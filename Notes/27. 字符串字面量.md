### C++ 字符串字面量核心笔记

- **1. 字符串字面量的本质与空终止符**
  - 字符串字面量是被双引号 `""` 包裹的字符序列。
  - 在内存中，编译器会自动在字面量的末尾隐式添加一个空终止符 `\0`（数值为 0），用于告诉计算机该字符串在哪里结束,。例如，`"Cherno"` 看起来是 6 个字符，但它实际是一个占用 7 个字节的 `const char` 数组。
- **2. 存储在只读内存与不可变性**
  - 字符串字面量存储在二进制文件中的只读数据段中。
  - 因此，必须使用 `const char*` 来指向它。如果尝试将其声明为非 const 的 `char*` 并试图修改其中的字符，将会引发未定义行为（在 Debug 模式下程序通常会因写入只读内存而崩溃）,。
  - 如果确实需要修改字面量的内容，请将其定义为字符数组 `char name[] = "Cherno";`。这样会将数据分配到栈上，从而允许自由修改。
- **3. 字符类型与编码前缀**
  - 普通的 `char` 占用 1 个字节（通常为 ASCII/UTF-8）。如果在前缀加上 `u8`，可以显式强制要求其为 UTF-8。
  - `wchar_t` 是宽字符类型，使用 `L"..."` 前缀。其大小取决于编译器和操作系统（Windows 上通常为 2 字节，Linux/Mac 上为 4 字节）,,。
  - C++11 引入了 `char16_t` 和 `char32_t`。它们分别使用前缀 `u"..."` (16位/2字节) 和 `U"..."` (32位/4字节)，非常适合处理诸如 UTF-16 和 UTF-32 的特殊字符集,。
- **4. C++14 的标准字符串字面量后缀 (`s`)**
  - 在包含 `<string>` 的前提下，C++14 允许在字面量引号末尾加上 `s`，如 `"Cherno"s`。这其实是一个隐式调用的操作符函数，它会立刻返回一个实际的 `std::string` 对象，而非底层的原始指针，这让字符串的拼接操作变得极其方便。
- **5. 原始字符串字面量 (Raw String Literals)**
  - 使用 `R"(...)"` 前缀可以创建原始字符串。编译器会忽略其中包含的换行或斜杠等所有的转义字符。
  - 这能让我们避免写大量的 `\n`，非常适合直接在代码中编写多行的文本、Shader 代码或者 JSON 片段。

### 示例代码

```
#include <iostream>
#include <string>

// 需要引入以下命名空间以使用字面量后缀 's'
using namespace std::string_literals;

int main() {
    // 1. 标准只读字符串字面量
    const char* name = "Cherno";
    // name = 'a'; // 绝对禁止！会导致程序崩溃或未定义行为

    // 2. 如果你需要修改字符串内容，必须使用数组将其分配到栈上
    char editableName[] = "Cherno";
    editableName = 'a'; // 完全合法，现在字符串变成了 "Charno"

    // 3. 不同长度和编码的字符前缀
    const wchar_t* name2 = L"Cherno";  // 宽字符 (2或4字节)
    const char16_t* name3 = u"Cherno"; // 固定 2 字节
    const char32_t* name4 = U"Cherno"; // 固定 4 字节

    // 4. C++14 的 's' 后缀，直接生成 std::string 对象进行拼接
    std::string stdName = "Cherno"s + " Hello";

    // 5. 原始字符串字面量 (忽略转义字符，支持直接换行)
    const char* multiLine = R"(Line 1
Line 2
Line 3)";

    return 0;
}
```
