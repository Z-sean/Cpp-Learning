### C++ 头文件 (Header Files) 核心笔记

- **1. 头文件的核心作用**
  - 在 C++ 中，如果想跨 `.cpp` 文件使用同一个函数或类型，**编译器必须先知道它的存在**。
  - 头文件用于专门存储这些**声明 (Declarations)**（而不提供具体定义），以便在程序中共享，避免手动复制粘贴带来的代码重复。
- **2. `#include` 的本质**
  - 它是一个预处理指令。底层逻辑非常简单：直接打开对应的头文件，将其内容完全复制并粘贴到当前的 `.cpp` 翻译单元中。
- **3. 头文件保护 (Header Guards)**
  - 为了防止同一个头文件被同一个 `.cpp` 文件多次包含从而引发“重复定义”错误（例如多次定义同一个 `struct`），必须使用头文件保护。
  - 现代 C++ 推荐直接在头文件顶部写上 `#pragma once`。
  - 传统的兼容写法是使用宏定义：`#ifndef`、`#define` 和 `#endif`。
- **4. `< >` 与 `" "` 的区别**
  - `< >`（尖括号）：告诉编译器去其设置的“包含路径”中搜索文件，通常用于标准库（如 `<iostream>`）。
  - `" "`（双引号）：通常用于包含相对于当前文件路径下的本地文件（如 `"Log.h"`）。
- **5. C++ 标准库命名细节**
  - 像 `iostream` 这样的 C++ 标准库头文件没有 `.h` 后缀，这主要是为了与旧的 C 语言标准库头文件区分开来。

### 相关示例代码

**`Log.h` (头文件：仅包含声明)**

```
#pragma once // 防止该头文件在同一个 .cpp 中被多次包含

// 函数声明，向编译器承诺存在此函数
void Log(const char* message);
```

**`Log.cpp` (源文件：包含具体定义)**

```
#include "Log.h" // 验证声明与定义匹配
#include <iostream> // 使用尖括号引入标准库

// 提供函数的具体实现主体
void Log(const char* message) {
    std::cout << message << std::endl;
}
```

**`main.cpp` (源文件：调用函数)**

```
#include "Log.h" // 使用双引号引入本地同目录下的头文件

int main() {
    // 编译器因为看到了 Log.h 中的声明，所以允许这里的调用
    Log("Hello World!");
}
```
