### C++ 数组 (Arrays) 核心笔记

- **1. 数组的本质与排布**
  - 数组是相同类型变量的集合，在内存中是**连续存储**的（例如 5 个 `int` 会在内存中连续占用 20 个字节）。它主要用于避免程序员手动声明大量零散的变量。
- **2. 索引与越界危险**
  - 数组定义如 `int example;`，由于 C++ 索引从 `0` 开始，所以有效索引为 `0` 到 `4`。
  - **内存越界**：访问不存在的索引（如 `example[-1]` 或 `example`）会引发内存访问违规。这不仅容易导致程序崩溃，甚至可能在不知情的情况下覆盖其他变量的数据，产生极难排查的 Bug。
- **3. 数组与指针的底层关联**
  - 在 C++ 中，数组名本质上是一个指向该内存块起始位置的指针。
  - 使用索引操作 `example` 在计算机底层实际上等价于指针算术 `*(example + 2)`，即指针向后偏移两个整数的位置并解引用。
- **4. 栈分配 vs 堆分配**
  - **栈分配 (Stack)**：如 `int example;`，生命周期由作用域自动管理，性能最优。
  - **堆分配 (Heap)**：如 `int* another = new int;`。使用 `new[]` 分配的堆内存必须使用匹配的 `delete[]` 关键字手动释放，否则会导致内存泄漏。堆分配还会带来内存间接访问（Indirection），这会带来性能损耗。
- **5. 维护数组大小与现代替代方案**
  - 对于栈分配的数组，可以使用 `sizeof(example) / sizeof(int)` 的技巧来计算元素个数。但这招对堆分配的指针完全无效，因为只会返回指针本身的大小。
  - 现代 C++11 引入了 `<array>` 库中的 `std::array`，它内置了边界检查功能，并能通过 `.size()` 随时跟踪自身大小，是比原始数组更安全的替代方案。

### 相关示例代码

```
#include <iostream>
#include <array>

int main() {
    // 1. 栈分配数组 (Stack Allocation)
    int example;

    // 使用 for 循环遍历并赋值
    for (int i = 0; i < 5; i++) {
        example[i] = 2; // 底层等同于 *(example + i) = 2;
    }

    // 2. 堆分配数组 (Heap Allocation)
    int* heapArray = new int;
    heapArray = 5;

    // 必须手动使用带方括号的 delete[] 释放内存
    delete[] heapArray;

    // 3. 栈数组获取元素数量的技巧
    // sizeof(example) 为 20 字节，sizeof(int) 为 4 字节，结果为 5
    int count = sizeof(example) / sizeof(int);

    // 4. 现代 C++11 推荐的标准数组 std::array
    std::array<int, 5> modernArray;
    modernArray = 10;

    // std::array 可以直接安全地获取大小
    int modernCount = modernArray.size();

    return 0;
}
```
