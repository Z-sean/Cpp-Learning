# C++ 笔记：动态数组 (std::vector)

## 1. 核心概念

- `std::vector` 是 C++ 标准模板库 (STL) 提供的一个动态数组容器。
- 与大小固定的原生数组不同，`vector` 可以根据需要自动改变大小，它允许你不断向其中添加元素。
- **底层原理**：当现有容量不足以容纳新加入的元素时，`vector` 会在堆 (Heap) 上分配一块更大的新内存，将旧数据复制到新内存中，并删除旧的内存块。

## 2. 内存与性能注意事项

- **连续内存**：`vector` 中的数据在内存中是连续存储的。通常建议直接在 `vector` 中存储对象本身（而不是对象的指针），这样可以最大化利用 CPU 缓存，提高遍历速度。但如果对象非常大且频繁改变大小，复制数据的开销也会变大。
- **函数传参**：将 `vector` 作为参数传递给函数时，务必使用**常量引用 (`const std::vector<T>&`)**。如果不使用引用，C++ 会复制整个动态数组的数据，造成极大的性能浪费。

## 3. 示例代码

```cpp
#include <iostream>
#include <vector>

struct Vertex {
    float x, y, z;
};

// 最佳实践：使用常量引用传递 vector，避免巨大的内存复制开销
void PrintVertices(const std::vector<Vertex>& vertices) {
    // 使用范围 for 循环 (Range-based for loop) 进行遍历
    // 再次使用常量引用 (const Vertex&) 避免复制单个元素
    for (const Vertex& v : vertices) {
        std::cout << v.x << ", " << v.y << ", " << v.z << std::endl;
    }
}

int main() {
    // 创建一个存储 Vertex 对象的动态数组
    std::vector<Vertex> vertices;

    // 使用 push_back 向尾部添加元素
    vertices.push_back({1.0f, 2.0f, 3.0f});
    vertices.push_back({4.0f, 5.0f, 6.0f});

    // 常用操作：
    // 获取元素数量：vertices.size()
    // 删除第二个元素 (需使用迭代器)：vertices.erase(vertices.begin() + 1)
    // 清空所有元素：vertices.clear()

    PrintVertices(vertices);

    return 0;
}
```
