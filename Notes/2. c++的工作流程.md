### C++ 核心机制与构建流程笔记

- **1. 预处理 (Preprocessing)**
  - 编译器首先处理所有以 `#` 开头的预处理语句（例如 `#include`）。
  - `#include` 的本质非常简单：它就是打开对应的头文件，将其内容完全复制并粘贴到当前的 C++ 文件中。
- **2. 编译 (Compiling)**
  - 编译器将 C++ 源代码（文本文件）转换为 CPU 可以执行的机器码。
  - 在 C++ 中，**文件本身没有意义**，编译器将每个输入的 `.cpp` 文件作为一个独立的“翻译单元 (Translation Unit)”进行编译，每个 `.cpp` 文件都会生成一个对应的对象文件（在 Windows 下是 `.obj` 文件）。
- **3. 链接 (Linking)**
  - 链接器 (Linker) 的工作是将编译器生成的所有独立的 `.obj` 文件“缝合”拼接在一起，生成最终的可执行文件（如 `.exe`）。
  - 链接器还会负责将函数的调用与其具体的定义连接起来。
- **4. 声明与定义 (Declarations vs. Definitions)**
  - **声明**：相当于向编译器承诺“存在这样一个函数或变量”，但不提供具体实现。
  - **定义**：提供该函数或变量的实际代码主体 (Body)。
- **5. 入口点与特殊规则**
  - `main` 函数是程序的入口点，代码会从这里开始按顺序执行。
  - `main` 函数是一个特例：虽然它的返回类型是 `int`，但如果你不写 `return` 语句，编译器会自动假设它返回 `0`。
