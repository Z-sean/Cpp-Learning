# C++ 笔记：拷贝与拷贝构造函数 (Copying and Copy Constructors)

## 1. 浅拷贝与深拷贝 (Shallow Copy vs. Deep Copy)

- **默认的浅拷贝**：当你将一个变量（或对象）赋值给另一个时，C++ 默认执行的是浅拷贝。如果对象内部包含指针，**浅拷贝只会复制指针存放的内存地址，而不会复制指针指向的实际数据**。
- **浅拷贝的致命问题**：由于两个对象的指针指向同一块堆内存，当这两个对象超出作用域并分别调用析构函数（执行 `delete`）时，同一块内存会被释放两次，导致程序直接崩溃。
- **深拷贝**：为了解决这个问题，我们需要复制整个对象及其指向的完整内存。这就需要自定义一个能分配新内存并复制数据的**拷贝构造函数**。

## 2. 自定义拷贝构造函数 (Copy Constructor)

- 拷贝构造函数是在你复制相同类型的对象时被自动调用的特殊构造函数。
- 它的标准语法是接受一个自身类型的常量引用：`ClassName(const ClassName& other)`。
- 如果你的类设计为绝对不允许被复制（例如标准的 `std::unique_ptr`），你可以在声明时写上 `= delete` 来禁用拷贝构造函数。

## 3. 避免不必要的拷贝 (Avoiding Copies)

- 拷贝会分配堆内存，这是一个非常消耗性能的操作。
- **最佳实践**：当把对象作为参数传递给函数时，一定要使用**常量引用 (const reference)** 传递，比如 `void PrintString(const String& string)`。这使得函数直接引用现有的对象，而不是在底层默默创建一个开销巨大的新副本。

## 4. 示例代码：带深拷贝的 String 类

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* m_Buffer;
    unsigned int m_Size;

public:
    // 默认构造函数
    String(const char* string) {
        m_Size = strlen(string);
        m_Buffer = new char[m_Size + 1];
        memcpy(m_Buffer, string, m_Size);
        m_Buffer[m_Size] = 0; // 手动添加字符串结束符
    }

    // 自定义拷贝构造函数 (深拷贝)
    String(const String& other) : m_Size(other.m_Size) {
        std::cout << "Copied String!" << std::endl;
        m_Buffer = new char[m_Size + 1]; // 分配全新的内存块
        memcpy(m_Buffer, other.m_Buffer, m_Size + 1); // 复制数据
    }

    ~String() {
        delete[] m_Buffer;
    }

    friend std::ostream& operator<<(std::ostream& stream, const String& string);
};

std::ostream& operator<<(std::ostream& stream, const String& string) {
    stream << string.m_Buffer;
    return stream;
}

// 重点：使用 const 引用传参，避免触发拷贝构造函数
void PrintString(const String& string) {
    std::cout << string << std::endl;
}

int main() {
    String string = "Cherno";

    // 触发拷贝构造函数，进行深拷贝，两个对象拥有各自独立的内存
    String second = string;

    // 使用常量引用传参，不会打印 "Copied String!"
    PrintString(string);
    PrintString(second);

    return 0;
}
```
