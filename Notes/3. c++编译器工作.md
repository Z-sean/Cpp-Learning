### C++ 编译器工作原理笔记

- **1. 核心目标**
  - 编译器的主要任务是将我们编写的 C++ 文本源代码转换为计算机可以执行的机器码（最终结合链接器生成可执行文件）。
- **2. 预处理阶段 (Preprocessing)**
  - 在进行实际的词法分析和解析前，编译器会先处理所有以 `#` 开头的指令。
  - `#include`：它的工作方式非常简单直接，就是打开对应的头文件，并将其内容完全复制粘贴到当前的 `.cpp` 文件中。
  - `#define`：执行纯文本的查找与替换。
  - `#if` / `#endif`：根据条件决定是否将某段代码包含进后续的编译过程中。
- **3. 翻译单元与对象文件 (Translation Units & Object Files)**
  - 在 C++ 中，文件本身没有意义，编译器将每个输入的 `.cpp` 文件作为一个独立的“翻译单元”进行编译。
  - 头文件（`.h`）不会被单独编译，它们必须被包含在 `.cpp` 文件中参与编译。
  - 每一个参与编译的 `.cpp` 文件最终都会生成一个对应的“对象文件（Object File，后缀为 `.obj`）”。
- **4. 抽象语法树与机器码生成 (AST & Code Generation)**
  - 预处理完成后，编译器会将代码解析成“抽象语法树 (AST)”。
  - 随后，编译器将 AST 转换成 CPU 可以直接执行的底层汇编/机器码指令以及常量数据。
- **5. 代码优化 (Optimization)**
  - 根据配置（如 Debug 与 Release 模式），编译器会大幅改变最终生成的代码。
  - **常量折叠 (Constant Folding)**：例如代码中写了 `5 * 2`，编译器会在编译时直接算出结果 `10`，程序运行时不需要再做任何计算，这能极大提升性能。
