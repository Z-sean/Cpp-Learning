# C++ 笔记：宏 (Macros)

## 1. 核心概念

在 C++ 中，宏是通过**预处理器（Preprocessor）指令定义**的。当编译 C++ 程序时，预处理器会在正式编译之前运行，**查找并直接将代码中的宏名称替换为预先定义的文本**。宏本质上就是一种纯文本的“查找并替换”操作，发生在编译器将代码转换为机器码之前。

## 2. 基础用法与带参数的宏

使用 `#define` 关键字即可定义宏。除了简单的纯文本替换，宏还可以接收参数，使其行为像函数一样。

```cpp
#include <iostream>

// 基础文本替换：将 WAIT 替换为 std::cin.get()
#define WAIT std::cin.get()

// 带参数的宏：自动将传入的 x 替换到对应的输出流位置
#define LOG(x) std::cout << x << std::endl

int main() {
    LOG("Hello World"); // 预处理后变成: std::cout << "Hello World" << std::endl;
    WAIT;               // 预处理后变成: std::cin.get();
    return 0;
}
```

*注意：强烈建议不要用宏来替换常规语法（比如把 `{` 替换为 `OPEN_CURLY`），这会让代码变得难以阅读和维护。*

## 3. 核心应用场景：条件编译 (Conditional Compilation)

宏在实际开发中最常见且最有价值的用途是**调试与条件编译**。例如，你可以配置只在 Debug（调试）模式下打印日志，而在 Release（发布）模式下将日志宏替换为空，从而完全剥离日志代码以提升性能。

```cpp
#include <iostream>

// 通过修改这个值 (通常在 IDE 或构建系统中配置) 来切换模式
#define PR_DEBUG 1

#if PR_DEBUG == 1
    #define LOG(x) std::cout << x << std::endl
#else
    #define LOG(x) // 如果不是 Debug 模式，将其替换为没有任何内容的空文本
#endif

int main() {
    // 如果 PR_DEBUG 为 1，正常打印。如果为 0，这行代码在预处理阶段就会被完全删除。
    LOG("This is a debug message");
    return 0;
}
```

## 4. 多行宏定义

如果你需要定义包含多行代码的复杂宏，必须在每一行的末尾添加反斜杠 `\` 以转义换行符，告诉预处理器下一行也是宏的一部分。 *注意：反斜杠 `\` 后面必须紧跟换行，绝对不能留有空格，否则会导致语法错误。*

```cpp
#define MAIN int main() \
{\
    std::cin.get(); \
}
```
