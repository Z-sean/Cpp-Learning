# C++ 笔记：使用外部库与静态链接 (Using Libraries & Static Linking)

## 1. 核心概念

- **库的组成部分**：C++ 中的外部库通常由两部分组成：`include` 目录（包含头文件，提供函数声明）和 `lib` 目录（包含库文件，提供函数定义/预编译的二进制代码）。
- **项目管理建议**：为了让其他人克隆你的代码库后能直接编译运行，推荐将外部库文件直接放在你的项目目录（如建立一个 `Dependencies` 文件夹）中，而不是依赖外部的包管理器或绝对路径。
- **静态链接 (Static Linking)**：在编译时将库的二进制代码直接打包进你的可执行文件（如 `.exe`）中。这种方式通常比动态链接更快，因为编译器和链接器可以执行更多优化，且运行时不需要额外的 `.dll` 文件。

## 2. 在 Visual Studio 中配置静态链接

以引入 `GLFW` 库为例，正确配置静态链接需要分为三步：

1. **配置包含目录 (Include Directories)**：让编译器能找到库的头文件。
   - 路径：项目属性 -> C/C++ -> General -> Additional Include Directories
   - 建议使用宏 `$(SolutionDir)` 来设置相对路径，例如：`$(SolutionDir)Dependencies\GLFW\include`。
2. **配置库目录 (Library Directories)**：让链接器知道去哪个文件夹寻找库文件。
   - 路径：项目属性 -> Linker -> General -> Additional Library Directories
   - 添加路径，例如：`$(SolutionDir)Dependencies\GLFW\lib-vc2015`。
3. **配置链接器输入 (Linker Input)**：明确告诉链接器要链接的具体是哪一个库文件。
   - 路径：项目属性 -> Linker -> Input -> Additional Dependencies
   - 添加具体的库文件名，例如：`glfw3.lib`。

## 3. 示例代码与注意事项

```cpp
#include <iostream>

// 1. 对于项目外部的第三方库，通常推荐使用尖括号 < > 来引入头文件
#include <GLFW/glfw3.h>

// 2. （可选）如果你没有头文件，想手动声明一个 C 语言库中的函数，
//    必须使用 extern "C" 防止 C++ 发生名称修饰 (Name Mangling) 导致链接失败。
// extern "C" int glfwInit();

int main() {
    // 调用外部库的初始化函数
    int result = glfwInit();
    std::cout << result << std::endl;

    std::cin.get();
    return 0;
}
```

*注意：如果不配置链接器（即跳过上述第2、3步），即便代码可以正常编译，也会在最后报错 `unresolved external symbol`（无法解析的外部符号），因为链接器找不到该函数的实际定义。*
