# 重定义问题来源与解决

## 问题来源

- `#include`本质上是复制粘贴机制，多个源文件引入相同的头文件时，在最后的链接阶段，会出现多个源文件中都出现了同名的变量/函数，系统无法辨别。

- 宏定义只能**实现头文件不被同一个源文件中被重复展开**，但无法阻止多个源文件共同使用同一个头文件

- 举例如下:

- ```cpp
  /*
  demo/
  ├── main.cpp
  ├── test.cpp
  └── config.h
  */
  ```

- ```cpp
  //config.cpp
  #pragma once
  
  int count = 10;   // 错误：这是变量定义，不是声明
  ```

- ```cpp
  //main.cpp
  #include "config.h"
  
  int main() {
      return count;
  }
  ```

- ```cpp
  //test.cpp
  #include "config.h"
  
  void test() {
      count++;
  }
  ```

  ---

## 解决方案

- `extern` 关键字

- 该关键字表示此处是一个声明
- 函数不需要该关键字是因为当检查到没有`{}`时，就表示只是一个函数声明而不是实现，但变量不行，其底层存在默认赋值
