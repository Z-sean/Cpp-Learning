### C++ 指针 (Pointers) 核心笔记

- **1. 指针的本质**
  - 指针就是一个单纯的整数（数字），它存储的是某个数据的**内存地址**。
  - 指针的类型（如 `int*` 或 `double*`）在底层**毫无意义**，类型存在的唯一目的是为了方便程序员，并告诉编译器在读写该内存时应该处理多少个字节的数据。
- **2. 获取地址与无类型指针**
  - 使用 `&` (Ampersand) 操作符可以获取现有变量的内存地址。
  - `void*` 是一种完全无类型的指针，它只负责保存内存地址，不关心数据的类型。可以将指针初始化为 `0` 或更现代的 `nullptr` 来表示它当前无效。
- **3. 解引用 (Dereferencing)**
  - 在指针变量前使用 `*` (Asterisk) 操作符，可以访问或修改该内存地址里存储的数据。
  - **注意**：你不能直接解引用一个 `void*` 指针并向其写入数据，因为编译器不知道需要写入多少字节（比如 `int` 是 4 字节，`char` 是 1 字节），必须先为其指定确切类型。
- **4. 堆内存与双重指针**
  - 使用 `new` 关键字可以在堆（Heap）上分配内存，并返回指向该内存块起始位置的指针（例如 `new char` 分配 8 字节）。
  - 凡是使用 `new` 分配的内存，在使用完毕后必须手动调用 `delete`（或 `delete[]`）进行释放。
  - 指针本身也是存储在内存中的变量，因此你可以获取指针变量自身的内存地址，这就形成了**双重指针**（指向指针的指针，如 `char**`）。

------

### 相关示例代码

```
#include <iostream>

int main() {
    int var = 8;
    void* ptr = nullptr; // 创建一个无效的无类型指针

    // 1. 获取变量的内存地址
    int* intPtr = &var;

    // 2. 解引用：修改该地址中的数据
    *intPtr = 10; // 此时 var 的值也会变成 10

    // 3. 在堆上分配内存 (8 个 char 的大小，即 8 字节)
    char* buffer = new char;

    // 4. 双重指针：指向 buffer 这个指针变量自身的内存地址
    char** doublePtr = &buffer;

    // 5. 释放使用 new[] 分配的堆内存
    delete[] buffer;

    return 0;
}
```
