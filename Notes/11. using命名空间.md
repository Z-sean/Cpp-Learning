# 命名空间

- 在构建代码时，我们经常使用的`std::cin`表示从标准输入中读取内容。此处使用作用域操作符`(::)`的含义是：编译器应从操作符左侧名字所示的作用域中寻找右侧那个名字。

- Cpp提供了`using`声明的方式来简化每一次使用函数的复杂操作，通过该方式声明后，可以直接使用函数，不需要额外的前缀

- ```cpp
  using std::cin;
  int main() {
      int i ;
      //正确,cin和std::cin含义相同
      cin >> i;
      //错误,没有对应的using声明，必须使用完整的名字
      //cout << i;
      //正确，显示地从std中使用cout
      std::cout << i;
      return 0;
  }
  ```

---

- 根据规定，每一个using只能引入命名空间的一个成员变量，我们可以通过多次声明的方式来表示使用的函数

- ```cpp
  using std::cin;
  using std::endl;
  int main() {
      int i ;
      //正确,cin和std::cin含义相同
      cin >> i;
      //错误,没有对应的using声明，必须使用完整的名字
      //cout << i;
      //正确，显示地从std中使用cout
      std::cout << i << endl;
      return 0;
  }
  ```

---

## 头文件中不应该包含`using`声明

- 因为头文件会将内容全部拷贝在引用它的源文件中，这会导致所有使用该头文件的源文件都包含该声明。对于某些程序来说，无意间包含的名字，会导致命名冲突。
