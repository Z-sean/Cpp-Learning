# `Const`修饰符

## `const`基础

- 关键字，通过修饰，指定变量值不可变，提高代码的安全性与可维护性

- 通常放在变量类型之前，也可以放在类型之后

- 可以用一个常量初始化常量，也可以使用变量赋值给一个常量

- ```cpp
  const int a = 10;
  int const a = 10;
  //=================
  int num1 = 10;
  const int num2 = num1;
  const int num3 = 20;
  ```

- ⚠️:常量必须初始化

### 编译器对常量的处理

- `const` 修饰的变量在编译时会被视为只读，尝试修改其值会导致编译错误。此外，编译器可能会对 `const` 变量**进行优化，如将其存储在只读内存区域**

- **默认情况下，`const`对象只对于当前所在文件区域有效**

- ```cpp
  const int TEST = 10
  ```

  - 在编译阶段，编译器收集所有用到常量的地方，文件内所有的常量都会被替换为常量值
    - 所以常量必须初始化
  - 若程序包含多个源文件，常量对象在多个文件内都被使用，**为了避免重复定义，编译器默认const对象只在当前文件内生效，所以多文件中的同名常量是独立的**
  - 若需要共享常量值，需要在声明常量值时，添加关键字`extern`

## `const`与引用

- 我们可以把引用绑定在常量上，俗称对常量的引用，当引用作为常量时，我们**无法对引用的值进行修改**

- ```cpp
  const int num =10;
  const int & n = num;
  n = 11;//❌
  
  ```

- 我们不能使用非常量的引用来引用一个常量值

  - 因为避免引用对引用值(常量)的修改

- ```cpp
  int & bar = num;//❌
  ```

- 相反的，常量引用可以引用一个非常量值

- ```cpp
  int num2 = 11;
  const int & bar2 = num2
  ```

- 通过该方式对变量进行引用，该**引用只读**，无法修改，**是一个安全引用**

---

- ```cpp
  double dval = 3.14;
  int & rd = dval;//错误，因为类型不匹配
  ```

- ```cpp
  double dval = 3.14;
  const int & ri = dval;
  ```

  - 通过常量引用的方式，运行上段代码编译通过，底层上是创建了一个临时对象，将 `dval` 的值经过**类型转换后用于初始化该临时对象**，然后让 `const int&` 绑定到这个临时对象上。

  - ```cpp
    //上面代码会做隐士转换,相当于下面代码
    const int temp  = dval;
    const int &rt = temp;
    ```

---

- 常量对引用的约束只限于引用本身，对引用的值不作要求，可以是普通变量也可以是常量



## `const`与指针

- 类似于引用，指向常量的指针不能修改用于修改其指向的值

- 想要存放常量的地址，必须使用指向常量的指针

  - ```cpp
    //PI 是一个常量,它的值不能改变
    const double PI = 3.14;
    //错误，ptr是一个普通指针
    //double * ptr = &PI;
    //正确,cptr可以指向一个双精度常量
    const double *cptr = &PI;
    //错误，不能给*ptr赋值
    //*cptr = 3.14;
    ```

  - **指针的类型必须与所指对象一致**

- **允许指向常量的指针指向一个非常量值**，那么这个指针就是只读的，是一个安全的指针。

---

- 指针本身是一个对象，所以指针本身可以被定义为一个常量，常量指针与其指向的值是一个强绑定关系，无法再指向其他变量

- 常量指针必须初始化

- ```cpp
  int errNumb = 0;
  //curErr是一个常量指针，指向errNumb
  int * const curErr = &errNumb;
  const double pi2 = 3.14;
  //pip 是一个指向常量对象的常量指针
  const double *const pip = &pi2;
  ```

- 指针是常量意味着指针所指向的值本身是否可以被修改要看值本身

> 判断思路：可以看作const先修饰左侧的类型，若左侧没有类型，则修饰右侧紧挨的类型。

## 顶层`const`

- 指针指向一个对象，指针本身也是一个对象，所以关于指针本身是常量还是指针指向一个常量是两个独立的问题
- 关于这两个问题的讨论，cpp中，将`const`分为了**顶层`const`**和**底层`const`**
  - 区分`const`类型主要依靠:**`const`约束的是变量本身还是其指向的对象？**
  - 所以，一般的常量都是顶层`const`,而指向常量的指针，这个指针指向的常量是一个底层`const`
- 在使用指针与引用时，需要特别区分`顶层const`和`底层const`，而一般情况下的常量，都是修饰自身，按`顶层const`处理

## `constexpr`和常量表达式

- 常量表达式指的是值不会变且在编译过程中就可以得到结果的表达式

- 用常量表达式初始化的`const`对象也是常量表达式

- ```cpp
  int GetSize(){
      return 20;
  }
  
  {
      //max_files是一个常量表达式
      const int max_files = 20;
      //limit是一个常量表达式
      const int limit = max_files + 10;
      //staff_size不是常量表达式,无const声明
      int staff_size = 20;
      //sz不是常量表达式,运行时计算才得知
      const int sz = GetSize();
  }
  ```

- 在实际使用中，我们很难辨别初始值是否是一个常量表达式

- 在C++11中，推出关键字`constexpr`来要求编译器验证变量值是否是一个常量表达式

  - 声明`constexpr`的变量一定是一个常量，且必须用常量表达式进行初始化

  - ```cpp
    //20是一个常量表达式
    constexpr int mf = 20;
    //mf+1是一个常量表达式
    constexpr int limit = mf + 10;
    //错误，GetSize()不是一个常量表达式，需要运行才能返回
    //constexpr int sz = GetSize();
    ```

- 我们无法使用函数作为常量表达式，但在**新标准中，允许使用一种简单的函数作为常量表达式。这个函数应该应该足够简单以使得编译时就可以计算其结果**

  - ```cpp
    inline constexpr int GetSizeConst() {
        return 1;
    }
    ```

  - 为了避免在多个源文件中包含同一个头文件而导致的多重定义错误，可以将 `constexpr` 函数声明为 `inline`

    - `inline` 关键字允许在多个翻译单元中定义同一个函数，而不会引起链接错误

    - `inline`允许在头文件中定义变量与函数，不会因为头文件被多次引用而在链接阶段抛出重复定义错误

    - ```cpp
      constexpr int sz = GetSizeConst();
      ```

### 指针与constexpr

- 在constexpr声明中如果定义了一个指针，限定符constexpr仅对指针有效，与指针所指的对象无关：

- ```cpp
  //p是一个指向整形常量的指针
  const int * p = nullptr;
  //q是一个指向整数的常量指针
  constexpr int *q = nullptr;
  ```

  - 一个`constexpr`指针的初始值必须是`nullptr`或者0，或者是存储于某个固定地址中的对象
  - 定义于所有函数体之外的对象其地址固定不变（全局变量），能用来初始化`constexpr`指针
