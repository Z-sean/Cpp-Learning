# Vector

## 基础概念与初始化

- 标准模板库 (STL) 中的一种序列容器，能够**动态地管理**可变大小的数组

| **特性**      | **数组 (Array)**            | **向量 (Vector)**        |
| ------------- | --------------------------- | ------------------------ |
| 大小          | 固定大小 (编译时或运行时)   | **动态可变大小**         |
| 内存管理      | 手动管理 (需要预留足够空间) | **自动管理 (自动扩展)**  |
| 支持的操作    | 限制较多                    | **丰富的成员函数和操作** |
| 安全性        | 较低 (易发生缓冲区溢出)     | 较高 (通过成员函数检查)  |
| STL算法兼容性 | 低                          | 高                       |

---

### 初始化

- 使用向量时必须包含其声明的头文件`#include <vector>`
- 若需要定义字符串向量，还需要配合`\#include <string>`

- ```cpp
  #include<vector>
  ```

---

- vector有五种声明以及初始化方式

- ```cpp
  #include<vector>
  //默认初始化
  std::vector<int> vec1;
  //指定大小和初始值的初始化
  std::vector<int> vec2(5, 10);
  //使用初始化列表
  std::vector<int> vec3 = {1, 2, 3, 4, 5};
  //拷贝赋值
  std::vector<int> vec4(vec3);
  //移动构造
  std::vector<int> vec5(std::move(vec4));
  ```

## 向量操作

### 向量大小与容量

- `size()`：返回向量中**当前实际包含**的元素数量 。  
- `capacity()`：返回向量目前为止**分配的存储容量** 。  
- `empty()`：检查向量是否为空 。  

> `capacity()` 并不一定精确匹配 `size()` ！它表示在需要重新分配内存之前，向量到底能装多少东西 。
>
> 为了避免频繁为向量分配空间，一般与其实际存储数量不一致

---

### 添加&删除与访问

- 增&删
  - **`push_back()`**：在向量末尾添加一个元素
  - **`pop_back()`**：移除向量末尾的元素 
  - `insert()` / `erase()`：在指定位置插入或移除元素 
  - `clear()`：移除所有元素，一键清空
- 访问元素
  - **`operator[]`**：通过索引访问元素（就像传统数组一样，如 `vec[0]`）
  - **`at()`**：通过索引访问元素，**带边界检查**
  - `front()` / `back()`：快速访问第一个或最后一个元素

> 如果访问越界（比如一共3个水果，你非要访问第5个），**使用 `[]` 可能会导致未定义行为，而使用 `at()` 会抛出 `std::out_of_range` 异常**，从而让程序有机会捕获错误而不是直接崩溃 。

> 以上数据操作都是直接作用于原数据上进行的，在进行增删时，直接在原数据上进行，而在进行访问时，是对原数据的引用执行的
