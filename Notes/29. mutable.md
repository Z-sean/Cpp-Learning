### C++ `mutable` 关键字核心笔记

- **核心概念**：`mutable` 意为“可变的”，允许在通常不可变的上下文中修改变量。在 C++ 中主要有两个完全不同的使用场景。
- **1. 与类中的 `const` 方法结合（最常见用法）**
  - 通常，标记为 `const` 的类方法承诺不会修改类的任何成员变量。
  - 如果某个成员变量（例如用于追踪方法调用次数的调试计数器 `debugCount`）被标记为 `mutable`，那么即使在 `const` 方法内部，该变量也允许被修改。
- **2. 在 Lambda 表达式中使用**
  - 当 Lambda 表达式按值（通过拷贝）捕获外部变量时，默认情况下你不能在 Lambda 主体内部修改这个拷贝。
  - 通过在 Lambda 表达式的参数列表后添加 `mutable` 关键字，你就可以修改这些按值捕获的变量。**注意**：这只会修改 Lambda 内部的局部拷贝，完全不会影响外部的原始变量。

------

### 示例代码

```
#include <iostream>
#include <string>

// 场景 1：mutable 与 const 类方法
class Entity {
private:
    std::string m_Name;
    mutable int m_DebugCount = 0; // 标记为 mutable

public:
    Entity(const std::string& name) : m_Name(name) {}

    // 这是一个 const 方法，承诺不修改核心数据，但可以修改 mutable 变量
    const std::string& GetName() const {
        m_DebugCount++; // 完全合法
        std::cout << "GetName called " << m_DebugCount << " times." << std::endl;
        return m_Name;
    }
};

int main() {
    Entity e("Cherno");
    e.GetName();

    // 场景 2：mutable 与 Lambda 表达式
    int x = 8;

    // 按值捕获 x，使用 mutable 使其可在 Lambda 内部修改
    auto myLambda = [x]() mutable {
        x++; // 如果没有 mutable 关键字，这行代码会报错
        std::cout << "Lambda inside x: " << x << std::endl; // 输出 9
    };

    myLambda();

    // 外部的 x 不受 Lambda 内部修改的影响
    std::cout << "Lambda outside x: " << x << std::endl; // 仍然输出 8

    return 0;
}
```
