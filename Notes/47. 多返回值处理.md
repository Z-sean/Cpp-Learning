# C++ 笔记：处理多个返回值 (Multiple Return Values)

在 C++ 中，函数默认只能返回一种数据类型。如果需要返回多个变量，有四种常见的方法：

## 1. 引用或指针传参 (Pass by Reference/Pointer)

通过将变量作为引用（或指针）传递给函数，直接在函数内部修改它们的值，通常被称为“输出参数”。

- **优点**：性能好，没有额外的结构拷贝或堆分配开销。
- **缺点**：代码写法略显笨重，调用前必须先声明好变量。

```cpp
void ParseShader(const std::string& filepath, std::string& outVertex, std::string& outFragment) {
    outVertex = "vertex code";
    outFragment = "fragment code";
}
```

## 2. 返回数组 (std::array 或 std::vector)

如果你需要返回的多个变量**数据类型完全相同**，可以返回一个数组或向量。

- 推荐使用栈分配的 `std::array`，如果长度需要动态变化则使用 `std::vector`。
- 绝对不推荐使用 `new` 返回原始数组指针，因为这会产生不必要的堆内存分配。

## 3. 使用 std::pair 或 std::tuple

如果返回的变量**类型不同**，标准库提供了 `std::pair`（用于两个值）和 `std::tuple`（用于任意数量的值）。

- **缺点**：代码可读性极差。你必须使用 `result.first` 或 `std::get<0>(result)` 这种方式来获取数据，完全失去了变量原本的名字和语义意义，很容易混淆。

```cpp
#include <iostream>
#include <utility> // std::pair 需要包含这个头文件

// 函数：计算除法，同时返回商和余数
std::pair<int, int> divide(int dividend, int divisor) {
    // 使用列表初始化 {值1, 值2} 直接返回
    return {dividend / divisor, dividend % divisor};
}

int main() {
    // 方式 A：使用 C++17 结构化绑定（强烈推荐，最直观）
    auto [quotient, remainder] = divide(10, 3);
    std::cout << "C++17 方式 -> 商: " << quotient << ", 余数: " << remainder << "\n";

    // 方式 B：传统方式（通过 .first 和 .second 访问）
    std::pair<int, int> result = divide(10, 3);
    std::cout << "传统方式 -> 商: " << result.first << ", 余数: " << result.second << "\n";

    return 0;
}
```

```cpp
#include <iostream>
#include <tuple>   // std::tuple 需要包含这个头文件
#include <string>

// 函数：返回学号(int)、姓名(string)、GPA(double)
std::tuple<int, std::string, double> getStudentInfo() {
    return {101, "Alice", 3.9};
}

int main() {
    // 方式 A：使用 C++17 结构化绑定（推荐，直接将 tuple 解包到变量中）
    auto [id, name, gpa] = getStudentInfo();
    std::cout << "C++17 方式 -> 学号: " << id << ", 姓名: " << name << ", GPA: " << gpa << "\n";

    // 方式 B：传统方式（使用 std::get<索引> 访问）
    auto info = getStudentInfo();
    std::cout << "传统方式 -> 学号: " << std::get<0>(info) 
              << ", 姓名: " << std::get<1>(info) 
              << ", GPA: " << std::get<2>(info) << "\n";

    return 0;
}
```



## 4. 自定义 Struct (最佳实践 / Best Practice)

The Cherno 强烈推荐的方式是专门为返回值定义一个结构体 (`struct`)。

- **优点**：代码极其清晰、易读，每个返回值都有确切的名称，绝对不会混淆。

```cpp
#include <iostream>
#include <string>

struct ShaderProgramSource {
    std::string VertexSource;
    std::string FragmentSource;
};

ShaderProgramSource ParseShader(const std::string& filepath) {
    // 假设这里是读取文件并解析的逻辑
    return { "vertex code", "fragment code" };
}

int main() {
    ShaderProgramSource source = ParseShader("Basic.shader");
    std::cout << source.VertexSource << std::endl;
    std::cout << source.FragmentSource << std::endl;
    return 0;
}
```
