### C++ 成员初始化列表 (Member Initializer Lists) 核心笔记

- **1. 什么是成员初始化列表？**
  - 它是 C++ 构造函数中用来初始化类成员变量的一种特定语法。它可以让你的构造函数体保持干净整洁。
- **2. 基本语法与严格的顺序规则**
  - 在构造函数参数列表的花括号前加上冒号 `:`，然后列出需要初始化的成员变量及初始值，多个成员之间用逗号分隔。
  - **关键规则**：你**必须严格按照变量在类中声明的顺序**来编写初始化列表。无论你在初始化列表中怎样排列，编译器都会强制按照声明顺序来初始化变量。如果不按顺序写，可能会引发变量依赖的 Bug，部分编译器也会因此发出警告。
- **3. 为什么要使用它？（性能差异）**
  - **避免两次构造**：这是使用初始化列表的最重要原因。如果你在构造函数体内部对对象类型的成员（比如 `std::string` 或自定义的类）进行赋值，该对象实际上会被构造两次：首先会调用一次默认构造函数进行初始化，然后又通过赋值操作创建并覆盖一个新的对象。
  - **提升性能**：使用成员初始化列表可以直接将参数传递给成员变量的构造函数，确保对象只被构造一次，避免了毫无意义的性能浪费。
  - 对于像 `int` 这样的基本数据类型，虽然在函数体内赋值不会有双重构造的性能开销，但作为最佳实践，建议对所有成员统一使用初始化列表。

### 示例代码

```
#include <iostream>
#include <string>

class Example {
public:
    Example() { std::cout << "Created empty Example" << std::endl; }
    Example(int x) { std::cout << "Created Example with int" << std::endl; }
};

class Entity {
private:
    // 注意声明顺序：先是 m_Name，再是 m_Example
    std::string m_Name;
    Example m_Example;

public:
    // 推荐做法：使用成员初始化列表，且严格遵守声明顺序
    Entity(const std::string& name)
        : m_Name(name), m_Example(8)
    {
        // 构造函数体非常干净，而且 m_Example 只会被构造一次
    }

    /*
    糟糕的做法（会导致性能浪费）：
    Entity(const std::string& name) {
        // 此时 m_Example 已经调用了默认构造函数
        m_Name = name;
        m_Example = Example(8); // 又创建了一个新的 Example 并覆盖，白白浪费性能
    }
    */
};

int main() {
    Entity e("Cherno");
    return 0;
}
```

------

- 使用默认构造函数，需要先创建一个对象，再初始化
- 使用列表初始化，是在创建时就得到一个初始化的对象
