### C++ 接口与纯虚函数核心笔记

- **1. 纯虚函数与接口的本质**
  - 纯虚函数相当于 Java 或 C# 等语言中的抽象方法或接口。
  - C++ 中并没有专属的 `interface` 关键字，接口本质上就是**只包含纯虚函数的类**。
- **2. 核心语法**
  - 在**虚函数声明的末尾加上 `= 0` 即可将其定义为纯虚函数**（例如 `virtual std::string GetClassName() = 0;`）。
- **3. 实例化限制**
  - 如果一个类包含了纯虚函数，那么这个类就无法被实例化（创建对象）。
  - 任何继承该基类的子类都**必须**提供该纯虚函数的具体定义，否则该子类也无法被实例化。
- **4. 接口的核心作用**
  - 接口用于强制子类实现特定的方法。它可以向编译器保证某个传入的对象一定具备特定功能，这让我们能够编写接收该接口类型的通用函数（如通用的打印函数）。

### 示例代码

```cpp
#include <iostream>
#include <string>

// 定义一个接口 (只包含纯虚函数的类)
class Printable {
public:
    virtual std::string GetClassName() = 0; // 纯虚函数
};

// Entity 类实现了 Printable 接口
class Entity : public Printable {
public:
    std::string GetClassName() override {
        return "Entity";
    }
};

// Player 继承自 Entity (自然也实现了接口)
class Player : public Entity {
public:
    std::string GetClassName() override {
        return "Player";
    }
};

// A 类直接实现 Printable 接口
class A : public Printable {
public:
    std::string GetClassName() override {
        return "A";
    }
};

// 通用函数：由于参数要求是 Printable 指针，编译器可以保证 obj 一定有 GetClassName 方法
void Print(Printable* obj) {
    std::cout << obj->GetClassName() << std::endl;
}

int main() {
    Entity* e = new Entity();
    Player* p = new Player();
    A* a = new A();

    Print(e); // 输出: Entity
    Print(p); // 输出: Player
    Print(a); // 输出: A

    // Printable* obj = new Printable(); // 错误！带有纯虚函数的类无法被实例化

    delete e;
    delete p;
    delete a;

    return 0;
}
```
