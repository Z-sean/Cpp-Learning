# C++ 笔记：局部静态变量 (Local Static)

## 1. 核心概念

在 C++ 中，当你考虑声明一个变量时，通常需要关注两个点：**作用域 (Scope)**（你在哪里可以访问它）和 **生命周期 (Lifetime)**（它在内存中存活多久）。

- 在局部作用域（例如函数内部）使用 `static` 关键字，可以使该变量的**生命周期延长至整个程序的运行期间**。
- 然而，它的**作用域仍然被限制在声明它的函数内部**，外部无法直接访问，这可以有效避免全局变量带来的命名空间污染。
- 局部静态变量只会在函数第一次被调用时初始化一次，后续的函数调用会直接使用并保留该变量上一次的状态。

## 2. 示例代码：局部静态计数器

如果不用 `static`，每次调用函数都会重新创建并初始化 `i`。使用 `static` 后，`i` 会在调用之间保持状态：

```cpp
#include <iostream>

void Function() {
    // 第一次调用时创建并初始化为 0，之后调用会跳过这一行
    static int i = 0;
    i++;
    std::cout << i << std::endl;
}

int main() {
    Function(); // 输出 1
    Function(); // 输出 2
    Function(); // 输出 3
    return 0;
}
```

## 3. 示例代码：优化单例模式 (Singleton Pattern)

局部静态变量的一个经典且强大的应用场景是实现单例模式。使用它可以极大地简化代码，无需在类外部手动去分配和定义静态成员实例指针。

```cpp
class Singleton {
public:
    static Singleton& Get() {
        // 局部静态实例：首次调用 Get() 时自动构造，程序结束时自动销毁
        static Singleton instance;
        return instance;
    }

    void Hello() {
        // 执行一些操作
    }
private:
    // 将构造函数设为私有，防止外部通过常规方式实例化
    Singleton() {}
};

int main() {
    Singleton::Get().Hello();
    return 0;
}
```
