### C++ 循环 (Loops) 核心笔记

- **1. 循环的核心作用**
  - 循环用于多次执行特定的代码块，例如重复打印文本，或用于维持持续运行的“游戏循环 (Game Loop)”以逐帧更新游戏状态。
- **2. `for` 循环**
  - 基本结构由分号隔开的三个部分组成：变量声明（如 `int i = 0`）、条件判断（如 `i < 5`）和迭代语句（如 `i++`）。
  - **执行顺序**：声明变量 -> 判断条件 -> 如果为真则执行循环体 -> 执行迭代语句 -> 再次判断条件。
  - **极致的灵活性**：`for` 循环非常灵活，你可以将声明或迭代语句移到循环外部或内部，甚至省略条件判断（默认为 `true`，这将产生死循环）。
- **3. `while` 循环**
  - 结构更简单，仅包含一个条件判断部分。
  - 它和 `for` 循环在底层功能上完全一样，两者可以相互转换。
  - **使用场景**：如果已经有一个现成的布尔状态需要监控（例如 `bool running = true`），使用 `while` 循环更加自然；如果需要跟踪具体的计数器或索引（比如遍历一个包含10个元素的数组），使用 `for` 循环是更好的选择。
- **4. `do-while` 循环**
  - 与普通循环不同，无论初始条件是否为真，`do-while` 循环的循环体都**保证至少会执行一次**，然后再判断是否继续循环。

------

### 示例代码

```
#include <iostream>

int main() {
    // 1. 标准 for 循环示例
    for (int i = 0; i < 5; i++) {
        std::cout << "Hello World from for loop!" << std::endl;
    }

    // 2. while 循环示例（逻辑上与上面的 for 循环完全等价）
    int j = 0;
    while (j < 5) {
        std::cout << "Hello World from while loop!" << std::endl;
        j++;
    }

    // 3. do-while 循环示例（即使条件一开始就是 false，也会先执行一次打印）
    bool condition = false;
    do {
        std::cout << "This runs at least once!" << std::endl;
    } while (condition);

    return 0;
}
```
