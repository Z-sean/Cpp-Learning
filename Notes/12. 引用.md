### C++ 引用 (References) 核心笔记

- **引用的本质**：引用本质上是**伪装的指针**，属于底层指针的“**语法糖**”，能让代码更直观易读。引用本身不是新变量，不占用额外内存，它只是现有变量的别名 (Alias)。
- **基本语法与初始化**：在数据类型后紧跟 `&` 符号来声明引用（例如 `int&`）。引用在声明时**必须立即初始化**并绑定到一个现有变量，不能像指针那样被设为空 (null) 或稍后赋值。
- **不可改变指向**：引用一旦绑定了某个变量，就永远不能更改为引用其他变量。如果尝试执行 `ref = b;`，它实际上只是把 `b` 的值赋给了 `ref` 原来绑定的变量，而不是改变引用的目标。
- **函数传参优化**：通过引用传递参数可以避免无意义的数据复制，并且允许函数在内部直接修改原始变量。相比于传入指针并在函数内解引用，使用引用会让代码更加干净整洁。

------

### 示例代码

```cpp
#include <iostream>

// 按引用传参，避免复制并允许直接修改原变量
void increment(int& value) {
    value++; // 直接修改，不需要像指针那样写成 (*value)++
}

int main() {
    int a = 5;
    int& ref = a; // ref 是 a 的别名

    ref = 2; // 修改 ref 等同于修改 a，此时 a 变成了 2

    int b = 8;
    ref = b; // 注意：这不是让 ref 重新引用 b，而是将 b 的值 (8) 赋给 a

    increment(a); // 传入 a，函数内部直接将 a 递增为 9

    std::cout << a << std::endl; // 输出 9
    return 0;
}
```
