### C++ 类与结构体 (Classes vs Structs) 核心笔记

- **1. 唯一的核心区别 (The Only Difference)**
  - 在 C++ 中，`class`（类）和 `struct`（结构体）在技术上几乎是完全相同的，唯一的区别在于**默认的可见性 (Visibility)**。
- **2. 默认可见性机制**
  - **Class**：默认的可见性是 `private`（私有）。如果你不写 `public:`，外部将无法访问其成员。
  - **Struct**：默认的可见性是 `public`（公有）。
- **3. 为什么 C++ 要保留 Struct？**
  - 主要是为了保持与 C 语言的**向后兼容性**。C 语言没有类，只有结构体。如果 C++ 移除 `struct` 关键字，现有的 C 代码将无法在 C++ 编译器中编译。
- **4. 实际开发中的使用约定 (Usage Conventions)**
  - 虽然它们在技术上可以互换，但在实际编程中，程序员通常会赋予它们不同的语义：
  - **何时使用 Struct**：通常用于表示“普通旧数据 (Plain Old Data, POD)”，即纯粹的变量集合（例如二维向量 `Vec2`，只包含 `x` 和 `y`）。虽然 struct 也可以有方法，但它的主要目的是组织简单数据，并且通常不建议在 struct 中使用继承。
  - **何时使用 Class**：用于具有复杂功能、庞大系统或需要使用继承体系的对象（例如包含 3D 模型、渲染代码、输入处理的 `Player` 类）。

### 示例代码

```
#include <iostream>

// 1. Struct 示例：适合简单的数据结构，默认是 public
struct Vec2 {
    float x, y; // 外部可以直接访问，不需要写 public:

    // struct 也可以包含方法来操作这些数据
    void Add(const Vec2& other) {
        x += other.x;
        y += other.y;
    }
};

// 2. Class 示例：适合复杂的对象，默认是 private
class Player {
    int speed; // 默认是 private，外部无法直接访问

public:
    // 必须明确标记为 public 才能在外部使用
    void Move(int xa, int ya) {
        // 复杂的移动和渲染逻辑...
    }
};

int main() {
    Vec2 position;
    position.x = 5.0f; // 完全合法，因为 struct 默认是公有的

    Player player;
    // player.speed = 10; // 错误！class 的成员默认是私有的

    return 0;
}
```
