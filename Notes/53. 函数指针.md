# C++ 笔记：函数指针 (Function Pointers)

## 1. 核心概念

- **本质作用**：函数指针允许你将函数赋值给一个变量，或者将函数作为参数传递给其他函数。
- **底层原理**：函数在编译后是一系列储存在二进制文件中的 CPU 指令，函数指针保存的就是这些指令在内存中开始执行的起始地址。

## 2. 语法与简化

- **获取地址**：可以直接使用函数名来获取函数指针（存在隐式转换），或者明确地在前面加上 `&` 符号。
- **原始声明**：C 风格的函数指针声明相对难读，格式类似于 `返回类型(*变量名)(参数类型)`。
- **简化最佳实践**：强烈推荐使用 `auto` 关键字让编译器自动推导类型，或者使用 `typedef` 为复杂的函数指针类型定义清晰的别名。

## 3. 实际应用场景

- **回调函数 (Callbacks)**：将函数作为参数传递给另一个函数（例如自定义的 `ForEach` 遍历机制），这让你可以在外部灵活定义具体的执行逻辑。
- **现代替代方案**：在现代 C++ 中，应对此类场景时通常会结合 **Lambda 表达式（匿名函数）** 来使用，以避免在外部写一堆只用一次的普通函数。

## 4. 示例代码

```cpp
#include <iostream>
#include <vector>

// 1. 定义一个普通函数
void PrintValue(int value) {
    std::cout << "Value: " << value << std::endl;
}

// 2. 接收函数指针作为参数的函数
// 参数说明：void(*func)(int) 代表一个返回 void、接收一个 int 的函数指针
void ForEach(const std::vector<int>& values, void(*func)(int)) {
    for (int value : values) {
        func(value); // 利用传入的函数指针调用具体逻辑
    }
}

int main() {
    std::vector<int> values = { 1, 5, 4, 2, 3 };

    // ==========================================
    // 基础用法：将函数赋值给变量
    // ==========================================

    // 原始写法：void(*function)(int) = PrintValue;
    auto function = PrintValue; // 推荐使用 auto 让编译器自行推导
    function(8); // 直接通过变量调用函数

    // 使用 typedef 简化并起别名
    typedef void(*PrintFunction)(int);
    PrintFunction funcAlias = PrintValue;

    // ==========================================
    // 进阶用法：将函数作为参数传递
    // ==========================================

    // 传入普通函数
    ForEach(values, PrintValue);

    // 传入 Lambda 表达式 (匿名函数)，使代码更加紧凑
    ForEach(values, [](int value) {
        std::cout << "Lambda Value: " << value << std::endl;
    });

    return 0;
}
```
