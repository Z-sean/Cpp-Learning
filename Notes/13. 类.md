### C++ 类与对象 (Classes) 核心笔记

- **1. 类的核心作用**
  - 面向对象编程 (OOP) 的基础。类主要用于将**数据 (Variables)**和**功能 (Functions)**组合在一起。
  - 相比于定义大量零散的变量（如 `playerX`, `playerY`, `playerSpeed`），类能让代码更整洁、更易于维护。
- **2. 基本语法与实例化**
  - 使用 `class` 关键字加唯一的类名来定义，主体用花括号 `{}` 包裹，且**结尾必须有分号 `;`**。
  - 由类类型创建的变量称为**对象 (Object)**，这个创建过程称为**实例化 (Instantiation)**。
- **3. 可见性 (Visibility)**
  - 默认情况下，C++ 类中的所有成员都是 `private`（私有的），意味着它们只能在类内部被访问。
  - 如果想在类外部（如 `main` 函数中）访问或修改这些成员，必须使用 `public:` 将它们标记为公有。
- **4. 方法 (Methods)**
  - 定义在类内部的函数被称为**方法 (Methods)**。
  - 方法可以直接访问同一个类中的成员变量，无需将它们作为参数传递，极大简化了代码。
- **5. 类的本质**
  - 类本质上是“语法糖”。它并没有提供在没有类的情况下（例如在 C 语言中）无法实现的全新功能，它只是帮助程序员更好地组织和维护代码。

------

### 相关示例代码

```
#include <iostream>

// 1. 定义一个类
class Player {
public: // 2. 将成员标记为公有，以便在类外部访问
    int x, y;
    int speed;

    // 3. 在类内部定义方法 (Method)
    void Move(int xa, int ya) {
        // 可以直接使用当前对象的 x, y 和 speed 变量
        x += xa * speed;
        y += ya * speed;
    }
};

int main() {
    // 4. 实例化一个 Player 对象
    Player player;

    // 5. 访问成员变量并赋值
    player.x = 0;
    player.y = 0;
    player.speed = 2;

    // 6. 调用类的方法
    player.Move(1, -1);

    return 0;
}
```
