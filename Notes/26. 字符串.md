### C++ 字符串 (Strings) 核心笔记

- **1. 字符串的本质**
  - 字符串本质上是字符（`char`）的数组或文本集合。
  - 在 C++ 中，普通的 `char` 占用 1 个字节的数据，通常用于表示 ASCII 字符。
- **2. C 风格字符串 (C-Style Strings)**
  - 使用 `const char*` 定义（例如 `const char* name = "Cherno";`）。
  - **空终止符 (Null Termination)**：在内存中，C 风格字符串的末尾会自动追加一个不可见的 `\0`（数值为 0）字符，用来告诉程序字符串在哪里结束。
  - 如果你手动定义字符数组但忘记加空终止符，程序在打印时会越界读取未知内存，直到遇到 0 为止，这会导致输出乱码。
- **3. C++ 标准库字符串 (`std::string`)**
  - 使用前需要包含头文件 `<string>`。
  - `std::string` 本质上是一个封装了 `char` 数组的类，内置了大量方便的字符串操作方法（例如 `.size()` 获取长度，`.find()` 查找子文本，以及使用 `+=` 或 `+` 拼接字符串）。
- **4. 核心性能陷阱：函数传参**
  - 当把 `std::string` 作为参数传递给函数时，默认会进行“值传递”。这意味着程序会在堆区重新分配内存并复制一整份相同的文本，这对性能是极大的浪费。
  - **最佳实践**：如果函数仅用于读取字符串，始终使用 `const std::string&`（常量引用）来传递参数，以避免无意义的内存拷贝。

------

### 示例代码

```
#include <iostream>
#include <string>

// 最佳实践：按 const 引用传递字符串以避免不必要的内存拷贝和分配
void PrintString(const std::string& text) {
    std::cout << text << std::endl;
}

int main() {
    // 1. C 风格字符串
    const char* cStyleName = "Cherno"; // 末尾在内存中隐式包含 '\0'

    // 2. C++ std::string
    std::string name = "Cherno";

    // 轻松的字符串拼接
    name += " Hello"; // name 现在变成了 "Cherno Hello"

    // 查找文本
    bool containsHello = name.find("Hello") != std::string::npos;

    // 将字符串传递给函数
    PrintString(name);

    return 0;
}
```
