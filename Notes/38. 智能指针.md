# C++ 笔记：智能指针 (Smart Pointers)

## 1. 核心作用

智能指针本质上是原始指针（Raw Pointer）的包装器，它的主要作用是**自动化内存管理**。使用智能指针分配堆内存时，你不需要手动调用 `delete`，当智能指针失效时，它会自动释放所指向的内存，从而有效防止内存泄漏。

## 2. 独占指针 `std::unique_ptr`

- **特点**：作用域指针 (Scoped Pointer)。当它超出作用域时，会自动销毁并释放内存。
- **限制**：**不能被复制**。因为如果允许复制，就会有两个 `unique_ptr` 指向同一块内存，当它们死亡时会导致对同一块内存释放两次。它的拷贝构造函数和拷贝赋值运算符都是被删除的 (`deleted`)。
- **最佳实践**：推荐使用 `std::make_unique` 来创建，这在处理异常时更安全。

**示例代码：**

```cpp
#include <iostream>
#include <memory> // 必须包含 memory 头文件

class Entity {
public:
    Entity() { std::cout << "Created Entity!" << std::endl; }
    ~Entity() { std::cout << "Destroyed Entity!" << std::endl; }
    void Print() {}
};

int main() {
    {
        // 推荐使用 std::make_unique 创建
        std::unique_ptr<Entity> entity = std::make_unique<Entity>();

        entity->Print(); // 可以像普通指针一样使用箭头操作符

        // std::unique_ptr<Entity> e0 = entity; // 报错：无法复制 unique_ptr

    } // 作用域结束，自动调用 Entity 的析构函数并释放内存

    return 0;
}
```

## 3. 共享指针 `std::shared_ptr`

- **特点**：使用**引用计数 (Reference Counting)** 机制。它会记录当前有多少个 `shared_ptr` 正在指向同一个对象。
- **原理**：每当你复制一个 `shared_ptr`，引用计数加 1；当一个 `shared_ptr` 死亡（超出作用域）时，引用计数减 1。只有当引用计数减到 0 时，底层内存才会被释放。
- **最佳实践**：必须使用 `std::make_shared` 来创建。因为 **`shared_ptr` 除了分配对象内存外，还需要分配一块控制块 (Control Block) 内存来存储引用计数**，使用 `make_shared` 可以将这两次分配结合为一次，从而提高效率。

**示例代码：**

```cpp
int main() {
    std::shared_ptr<Entity> e0;
    {
        // 使用 std::make_shared 创建共享指针
        std::shared_ptr<Entity> sharedEntity = std::make_shared<Entity>();

        // 允许复制，此时该 Entity 的引用计数变为 2
        e0 = sharedEntity;

    } // 内部作用域结束，sharedEntity 死亡，但引用计数减为 1，内存不会释放

    return 0;
    // e0 死亡，引用计数变为 0，内存释放
}
```

## 4. 弱指针 `std::weak_ptr`

- **特点**：通常与 `shared_ptr` 配合使用。将 `shared_ptr` 赋值给 `weak_ptr` 时，**不会增加引用计数**。
- **应用场景**：当你只想拥有一个对象的引用，但不想获取它的所有权（即不想阻止该对象被销毁）时使用。你可以询问 `weak_ptr` 其指向的底层对象是否仍然有效。

**示例代码：**

```cpp
int main() {
    std::weak_ptr<Entity> weakEntity;
    {
        std::shared_ptr<Entity> sharedEntity = std::make_shared<Entity>();

        // 赋值给 weak_ptr，引用计数保持为 1
        weakEntity = sharedEntity;

    } // 内部作用域结束，sharedEntity 被销毁，引用计数归零，内存立刻释放

    // 此时 weakEntity 指向的内存已被释放，它是无效的
    return 0;
}
```

## 5. 总结建议

在需要分配堆内存时，**首选 `std::unique_ptr`**，因为它的**开销最低**；如果确实需要在多个地方共享同一个对象，再退而求其次选择 `std::shared_ptr`。
