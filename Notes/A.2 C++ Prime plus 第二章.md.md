## `C++`程序的结构

### 在`linux`下创建`cpp`文件

```bash
touch 2-1.cpp
nano 2-1.cpp
# ctrl+O保存-->enter-->ctrl+x退出
g++ 2-1.cpp
# apt-get install g++ 没有安装需要先安装工具
ls #查看当前目录下的文件-->a.out
./ a.out #./表示指向当前目录下的指定文件
```

```cpp
//2-1.cpp
int main(void){
    return 0;
}
```

- `int main(void)`是函数头
- 花括号以及其中内容并称为函数体
- 语句需要以`;`结束

---

- `main()`被**启动代码调用**，启动代码是**编译器添加**的程序，`a.out`包含启动代码 + 我们编写的代码

- 启动代码是**操作系统与程序的桥梁**，`os`->启动代码->`main()`

- main的**返回值用于表示当前代码执行的状态**，0表示正常，-1或者非0值表示执行失败

- main()的()表示传递信息，**空表示没有任何传递信息，推荐使用void显式的表面是空的**

```cpp
//多种main书写方式
int main(void){}
int main(){} 
//以下可行但不推荐
main(){}
void main(){}
   
```

- 使用main函数是约定俗成的规矩，一般程序**从main开始执行**，如果没有main，那么会报错未定义main()
  - 例外情况:
    - DDL库，他不需要自己执行，而是需要别人调用，所以不需要main()
    - 嵌入式开发中，依靠地址执行，不在乎函数名是什么

## `#include`

- 如果需要输入输出，那么需要在代码的开头，添加以下代码:

- ```cpp
  #include<iostream>
  using namespace std;
  ```

- `using namespace std;`不是必须的，可以使用其他方式代替

- `#include<iostream>`该编译指令导致预处理器将iostream文件的内容添加到程序中。   

  - 在源代码被编译之前，替换或添加文本 ，原始文件没有被修改， 而是将源代码文件和iostream组合成一个复合文件， 编译的下一阶段将使用该文件。

- C语言的库文件在C++中做出了修改，其命名风格为在原始的C库名前加一个`c`并去掉了`.h`表示是C语言的相关库

  - 使用这样的方式不仅是命名方式的改变，也被允许使用命名空间

## 命名空间

```cpp
using namespace std;
```

- `using`是一个编译指令
  - 为了防止多个库文件中出现**同名的函数导致使用冲突**【编译器不知道具体使用哪一个函数】，使用命名空间并利用命名空间来分辨具体使用哪一个函数

- `cin`&`cout`都被存储在std命名空间下，以上写法也可以以以下方式输出

- ```cpp
  std::cout << "hello world！" << std::endl
  ```

- 使用using可以简化代码编写时的步骤，但也会带来一定的隐患

## 输出

- 在`C++`中，`""`表示字符串内容

- `cout`是一个预定义的对象，`<<`表示该语句会把字符串发给`cout`

- 输出是一个流，`cout`对象表示这种流，其属性是在`iostream`中定义的，包括

  - `<<`表示一个插入运算符，用于将右侧的信息插入流中

  - ```cpp
    cout << "Hello world";
    ```

  - 可以表示为将右侧字符串插入流中

> **运算符重载**
>
> - 在C语言中，`<<`表示按位左移运算符
> - 这种方式叫做运算符重载，通过重载，运算符实现不同的意义
> - 编译器通上下文来决定运算符的含义
> - 类似的还有*既表示乘法运算，也表示指针的解引用

- `endl`表示重起一行，在输出流中插入`end`l表示**光标移动在下一行开头**
  - 诸如此类对于`cout`具有特殊含义的符号被称为控制符
- `cout`并不会自动将光标移动在下一行，每一条`cout`语句的开头会继续在上一条输出的末尾

- C++同时支持一种旧的换行方式:换行符【`\n`】

## 语句&变量声明

```cpp
#include<iostream>
int main(void)
{
    using namespace std;
    int bar ;
    bar = 25;
    
    return 0;
} 
```

- C++要求变量**在使用前必须声明**，且**要求注明变量类型**
  - 声明的好处是避免后续变量使用时的拼写错误
  - C语言要求变量必须放在代码开头，但C++没有该限制，只要声明在使用前即可

- 赋值将从右到左执行
- `cout`输出会将数据类型相应的调整行为，这也是**运算符重载**的例子之一
  - 25在内存中是按照整型25的二进制存储的，输出是转换为字符串形式输出的

### `cout`拼接

- C++支持以下方式拼接一条语句:

- ```cpp

  cout << "now you have" ;
  cout << carrots ;
  cout << "carrots" ;
  cout << endl;
  //方式三
  cout << "now you have" 
       << carrots 
       << "carrots" 
       << endl;
  ```

### 有返回值的函数

- 以`sqrt()`函数为例子

- ```cpp
  x = sqrt(6.25);
  ```

- 以上过程涉及到了函数调用

  - 圆括号内的值是发送给函数的信息，以这种方式传递的信息叫做参数
  - `sqrt`叫做被调用函数
  - 函数调用的函数叫做调用函数==>`main`

- 语句执行结束后，函数调用的部分被替换为返回的值
  ![](D:\Work\Computer-Learning\Cpp-Learning\Screenshots\c++-primeplus学习截图\调用函数.png)![](D:\Work\Computer-Learning\Cpp-Learning\Screenshots\c++-primeplus学习截图\函数调用.png)

- 函数在使用前，编译器必须知道函数的参数类型和返回类型，提供该信息方式是函数原型语句，类似于变量声明

  - C++**应该为每一个函数提供原型**

  ```cpp
  double sqrt(double);//函数原型
  ```

  - 以上就是`sqrt`的函数原型，表明了函数的返回值类型与参数类型
  - `;`表示这是一条语句，而不是函数头
  - 在使用`sqrt`时，也**必须提供原型**，方式有：
    - 源代码中提供函数原型
    - 在**包含文件中提供**
  - 一般使用第二种方式，C++库的函数都在一个或者多个头文件中提供了函数原型。
  - 要注意区分函数原型与函数定义的概念

- 举例实现

- ```cpp
  include<iostream>
  #include<cmath>
  
  int main(void)
  {
          using namespace std;
          cout << "enter the floor area, in square feet, of your home:" << endl;
          double area;
          cin >> area;
          double size;
          size = sqrt(area);
          cout << "that's the equivalent of a square" << size << "feet to side" <>
  
  
          return 0; 
  }
  
  
  ```

- 在使用库函数时，编译器会在库文件中搜索需要的库函数，而是哪些库文件，**根据编译器的不同有所差别，部分编译器可能因为搜索不到对应的库文件而报错**，对应的库函数是未定义的

- 在找不到对于库文件的情况下，需要手动表面搜索地址:

- ```bash
  g++ sqrt.c -lm
  ```
