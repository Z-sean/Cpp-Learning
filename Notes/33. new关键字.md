# C++ 笔记：The NEW Keyword

## 1. 核心作用与原理

- **分配堆内存**：`new` 关键字主要用于在**堆 (Heap)** 上动态分配内存。它会在堆中寻找一块足够大的**连续空闲内存块**，并返回一个指向该内存地址的**指针**。
- **性能开销**：由于 `new` 需要在堆内存中寻找合适的空闲空间（通常通过底层的空闲列表来管理），这是一个相对较慢的过程，会带来性能开销。
- **底层机制**：`new` 是一个运算符 (Operator)。在底层，它通常会调用 C 语言的 `malloc` 函数来分配请求的字节数。

## 2. 针对对象的特殊操作

- 当使用 `new` 实例化类或结构体时，它除了分配所需的内存外，还会**自动调用该对象的构造函数 (Constructor)** 进行初始化。**这是 `new` 和直接使用 `malloc` 的最大区别（`malloc` 只分配内存，不调用构造函数）。**

## 3. 内存释放 (极度重要)

- **必须手动释放**：`new` 出来的内存**不会**自动释放。必须使用 `delete` 关键字手动释放，否则会导致内存泄漏 (Memory Leak)。
- **数组释放规则**：如果使用 `new[]` （带方括号）来分配数组，则必须使用匹配的 `delete[]` 操作符来释放该内存。

## 4. 示例代码

```
#include <iostream>
#include <string>

class Entity {
public:
    Entity() {
        std::cout << "Created Entity!" << std::endl;
    }
};

int main() {
    // 1. 为基本类型分配堆内存
    int* b = new int;      // 申请4字节内存

    // 2. 为数组分配堆内存
    int* array = new int; // 申请 50 * 4 = 200字节的连续内存

    // 3. 为对象分配堆内存 (分配内存并调用构造函数)
    Entity* e = new Entity();

    // 4. 高级用法：Placement new (指定内存地址进行初始化)
    // new(b) Entity();

    // --- 清理内存 ---
    delete b;            // 释放单个变量
    delete[] array;      // 释放数组必须加上 []
    delete e;            // 释放对象

    return 0;
}
```
