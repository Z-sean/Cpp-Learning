# C++ const 用法

### Core Concept (核心概念)

- **const 用来表达“不可通过当前名字修改”**，它既能修饰普通变量，也能修饰引用、指针、函数返回值等。
- 学习 `const` 的核心不是记语法，而是分清：**对象本身是否是常量**，以及**当前访问路径是否允许修改对象**。来源：:contentReference[oaicite:0]{index=0}

### Key Points (关键知识点)

- **const 变量必须初始化**：
  - `const int a = 10;`
  - `const` 对象创建后不能再被赋值修改。
  - `const int a;` 是错误的，因为常量必须在定义时确定初始值。

- **const 的声明位置**：
  - `const int a = 10;`
  - `int const a = 10;`
  - 二者等价，通常推荐第一种写法。

- **const 对象默认仅在文件内有效**：
  - 在多个 `.cpp` 文件中定义同名 `const` 变量，默认是多个独立变量。
  - 如果希望多个文件共享同一个 `const` 对象，需要使用 **extern 声明 + 单一定义**。

- **跨文件共享 const 对象**：
  - 头文件中写声明：`extern const int bufSize;`
  - 源文件中写定义：`const int bufSize = 512;`
  - 这样所有文件访问的是同一个对象。

- **常量引用**：
  - `const int& r = a;`
  - 含义是：**不能通过 r 修改它绑定的对象**。
  - 常量引用可以绑定：
    - const 对象
    - 非 const 对象
    - 字面量
    - 表达式结果
    - 类型转换产生的临时量

- **const 引用不代表对象本身一定是 const**：
  - `int a = 10; const int& r = a;`
  - 不能通过 `r` 修改 `a`。
  - 但仍然可以直接通过 `a` 修改对象。

- **临时量对象**：
  - 当表达式结果需要被暂存时，编译器会创建一个未命名对象。
  - `const int& r = 3.14;` 可以成立，因为会先生成一个临时 `int`，然后引用绑定到它。

- **指向常量的指针**：
  - `const int* p = &a;`
  - 指针可以改指向别处。
  - 但不能通过 `p` 修改它指向的对象。
  - 重点：**const 修饰的是指向的内容，不是指针本身**。

- **常量指针**：
  - `int* const p = &a;`
  - 指针本身不能改指向。
  - 如果指向的是非 const 对象，可以通过 `p` 修改对象内容。
  - 重点：**const 修饰的是指针本身，不是指向的内容**。

- **指向常量的常量指针**：
  - `const int* const p = &a;`
  - 指针不能改指向。
  - 也不能通过指针修改对象内容。

- **顶层 const**：
  - 修饰对象本身。
  - 例如：`const int a`、`int* const p`。
  - 拷贝时通常会被忽略，因为拷贝的是值。

- **底层 const**：
  - 修饰复合类型所指向或引用的对象。
  - 例如：`const int* p`、`const int& r`。
  - 拷贝或赋值时不能随意丢弃底层 const。

- **底层 const 的限制**：
  - 可以把非 const 对象的地址赋给 `const int*`。
  - 不能把 `const int*` 赋给 `int*`。
  - 原因：后者会绕过 const 限制，导致可以通过普通指针修改 const 对象。

- **常量表达式**：
  - 值不会改变，并且能在编译期得到结果。
  - 字面量是常量表达式。
  - 用常量表达式初始化的 `const int` 也是常量表达式。
  - 运行时函数返回值不是常量表达式。

- **constexpr**：
  - `constexpr` 要求变量必须用编译期可求值的表达式初始化。
  - `constexpr` 变量一定是常量。
  - 它的价值是让编译器替你验证“这是不是常量表达式”。

- **constexpr 函数**：
  - 可以在编译期求值的函数。
  - 如果写在头文件中，通常配合 `inline`，避免多个源文件包含后出现重复定义问题。

- **constexpr 指针**：
  - `constexpr int* p` 中，`constexpr` 修饰的是**指针本身**。
  - 它表示 `p` 是一个常量指针。
  - 它不代表 `p` 指向的对象是 const。
  - `constexpr` 指针只能初始化为：
    - `nullptr`
    - `0`
    - 固定地址对象的地址，例如全局变量地址

### Code Snippet (示例代码)

- const 变量与常量引用：

    #include <iostream>

    int main() {
        int a = 10;

    ```cpp
    const int b = a; // 正确：const 变量必须初始化
    // b = 20;       // 错误：不能修改 const 对象
    
    const int& r = a; // 常量引用绑定非 const 对象
    
    // r = 30;        // 错误：不能通过 const 引用修改对象
    
    a = 30;           // 正确：a 本身不是 const，可以直接修改
    
    std::cout << "a = " << a << '\n';
    std::cout << "r = " << r << '\n';
    
    const int& temp = 3.14; // 正确：发生类型转换，绑定到临时 int 对象
    
    std::cout << "temp = " << temp << '\n';
    
    return 0;
    ```
    }

- 指针和 const：

    #include <iostream>

    int main() {
        int a = 10;
        int b = 20;
        const int c = 30;

    ```cpp
    const int* p1 = &a; // 指向常量的指针：不能通过 p1 修改对象
    p1 = &b;            // 正确：p1 本身可以改指向
    // *p1 = 100;       // 错误：不能通过 p1 修改指向的对象
    
    int* const p2 = &a; // 常量指针：p2 本身不能改指向
    *p2 = 100;          // 正确：a 不是 const，可以通过 p2 修改 a
    // p2 = &b;         // 错误：p2 是常量指针，不能改指向
    
    const int* const p3 = &c; // 指向常量的常量指针
    // *p3 = 200;             // 错误：不能修改指向的对象
    // p3 = &a;               // 错误：不能修改指针本身
    
    std::cout << "a = " << a << '\n';
    
    return 0;
    ```
    }

- 顶层 const 与底层 const：

    int main() {
        int a = 10;
        const int c = 20;

    ```cpp
    int* const p1 = &a; // 顶层 const：p1 本身是常量
    const int* p2 = &c; // 底层 const：p2 指向的对象不能被修改
    
    int* p3 = p1;       // 正确：拷贝时可以忽略顶层 const
    
    // int* p4 = p2;    // 错误：不能丢弃底层 const
    const int* p5 = &a; // 正确：可以增加底层 const 保护
    
    return 0;
    ```
    }

- constexpr 与常量表达式：

    #include <iostream>

    int GetSize() {
        return 20; // 普通函数：运行时才返回结果
    }

    inline constexpr int GetConstSize() {
        return 20; // constexpr 函数：可以在编译期求值
    }

    int globalValue = 100; // 全局变量地址固定

    int main() {
        const int maxFiles = 20;          // 常量表达式
        const int limit = maxFiles + 10;  // 常量表达式

    ```cpp
    int staffSize = 20;               // 不是常量表达式：没有 const
    const int sz = GetSize();         // 不是常量表达式：运行时求值
    
    constexpr int n = GetConstSize(); // 正确：编译期可求值
    
    constexpr int* p = &globalValue;  // 正确：全局变量地址固定
    *p = 200;                         // 正确：constexpr 只限制指针本身，不限制指向内容
    
    std::cout << limit << '\n';
    std::cout << staffSize << '\n';
    std::cout << sz << '\n';
    std::cout << n << '\n';
    std::cout << globalValue << '\n';
    
    return 0;
    ```
    }

### Common Pitfalls (避坑指南)

- **以为 const 变量可以先声明后赋值**：
  - 错误：`const int a;`
  - 正确：`const int a = 10;`

- **误以为 const 引用绑定非 const 对象后，对象就变成 const**：
  - `const int& r = a;` 只限制不能通过 `r` 改。
  - 不会改变 `a` 本身的类型。

- **误以为非常量引用可以绑定 const 对象**：
  - `const int ci = 10; int& r = ci;` 是错误的。
  - 原因：这会允许通过 `r` 修改 `ci`，破坏 const 约束。

- **混淆“指向常量的指针”和“常量指针”**：
  - `const int* p`：不能改 `*p`，可以改 `p`。
  - `int* const p`：可以改 `*p`，不能改 `p`。
  - `const int* const p`：`*p` 和 `p` 都不能改。

- **忽略底层 const**：
  - `const int*` 不能赋给 `int*`。
  - 这不是语法洁癖，而是为了防止通过普通指针绕过 const 修改对象。

- **把 const 等同于 constexpr**：
  - `const` 只表示不可修改。
  - `constexpr` 进一步要求能在编译期求值。
  - `const int sz = GetSize();` 是常量，但不一定是常量表达式。

- **误以为 constexpr 指针指向 const 对象**：
  - `constexpr int* p = &globalValue;`
  - 这里 `p` 是常量指针。
  - `*p` 仍然可以被修改，因为指向对象不是 const。

- **在头文件中随意定义非 const 全局变量**：
  - 会导致多个源文件包含后产生重复定义。
  - `const` 对象默认文件内有效，所以头文件中定义 `const int x = 10;` 不会共享同一个对象。
  - 要共享同一个 const 对象，使用 `extern const`。
