# C++ 笔记：运算符与运算符重载 (Operators and Operator Overloading)

## 1. 核心概念

- **什么是运算符**：运算符是用来代替函数执行特定操作的符号。除了常见的数学运算符外，C++ 中的解引用（`*`）、箭头（`->`）、`new`、`delete`、逗号（`,`）甚至括号（`()`）都是运算符。
- **运算符本质**：在底层，运算符仅仅是具有特殊名称的**函数**。
- **什么是运算符重载**：运算符重载允许你为自定义的数据类型（如 `class` 或 `struct`）定义或改变特定运算符的行为，赋予其新的意义。与 Java 等语言不同，C++ 提供了对运算符的完全控制权。

## 2. 最佳实践 (Best Practices)

- **克制使用**：只有在完全符合直觉的情况下才使用运算符重载（例如两个数学向量相加使用 `+`）。
- **保证代码可读性**：如果其他开发者必须专门查看你的类定义才能猜出某个运算符的作用，这就代表你的重载是糟糕的设计。
- **提供双重选择**：在编写库或 API 时，推荐同时提供普通函数（如 `Add()`）和重载的运算符（如 `operator+`），让用户自己决定使用哪种代码风格。

## 3. 示例代码：重载数学与比较运算符

下面是一个 `Vector2` 结构体的示例，展示了如何重载加法 `+`、乘法 `*` 以及比较运算符 `==` 和 `!=`。如果不使用重载，我们必须编写冗长且难以阅读的函数链（如 `position.Add(speed.Multiply(powerup))`）。

```cpp
#include <iostream>

struct Vector2 {
    float x, y;

    Vector2(float x, float y) : x(x), y(y) {}

    // 普通的方法实现加法
    Vector2 Add(const Vector2& other) const {
        return Vector2(x + other.x, y + other.y);
    }

    // 重载加号 (+) 运算符：通过关键字 operator 加上符号名称来定义
    Vector2 operator+(const Vector2& other) const {
        return Add(other); // 可以直接复用普通方法，或者写 return Vector2(x + other.x, y + other.y);
    }

    // 重载乘号 (*) 运算符
    Vector2 operator*(const Vector2& other) const {
        return Vector2(x * other.x, y * other.y);
    }

    // 重载等于 (==) 运算符
    bool operator==(const Vector2& other) const {
        return x == other.x && y == other.y;
    }

    // 重载不等于 (!=) 运算符
    bool operator!=(const Vector2& other) const {
        return !(*this == other); // 利用逻辑非运算符反转 equals 的结果
    }
};
```

## 4. 示例代码：重载输出流运算符 (<<)

为了能够直接使用 `std::cout << vector` 打印自定义对象，我们需要重载左移运算符 `<<`。这个重载必须写在类的**外部**，因为它需要接收输出流作为左操作数。它必须返回该流的引用，以便支持链式调用（如 `std::cout << a << b`）。

```cpp
#include <iostream>

// 定义在 Vector2 外部，接收输出流的引用和我们自定义类的常引用
std::ostream& operator<<(std::ostream& stream, const Vector2& other) {
    stream << other.x << ", " << other.y;
    return stream;
}

int main() {
    Vector2 position(4.0f, 4.0f);
    Vector2 speed(0.5f, 1.5f);
    Vector2 powerup(1.1f, 1.1f);

    // 利用重载的运算符，让代码像数学公式一样直观并遵循优先级
    Vector2 result = position + speed * powerup;

    // 利用重载的 == 运算符进行比较
    if (result == Vector2(4.55f, 5.65f)) {
        // 利用重载的 << 运算符直接打印对象
        std::cout << result << std::endl;
    }

    return 0;
}
```
