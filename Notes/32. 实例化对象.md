# C++ 笔记：创建与实例化对象 (Instantiating Objects)

在 C++ 中，实例化对象主要有两种方式，它们的核心区别在于**内存分配的位置**（栈或堆）以及**对象的生命周期**。

## 1. 在栈上创建对象 (Stack Allocation)

这是 C++ 中最快、也是最推荐的对象创建方式。

- **特点**：内存自动管理。当对象超出其作用域（例如函数或代码块结束处的右大括号 `}`）时，内存会自动被释放，对象被销毁。
- **局限性**：栈的内存空间有限（通常只有 1-2 MB）。如果对象非常大，或者你需要对象在当前作用域之外继续存活，则不能使用栈分配。

**示例代码：**

```
#include <iostream>
#include <string>

class Entity {
private:
    std::string m_Name;
public:
    Entity() : m_Name("Unknown") {}
    Entity(const std::string& name) : m_Name(name) {}
    const std::string& GetName() const { return m_Name; }
};

int main() {
    // 调用默认构造函数 (注意不要加空括号)
    Entity entity1;

    // 调用带参数的构造函数
    Entity entity2("Cherno");
    Entity entity3 = Entity("Cherno");

    std::cout << entity2.GetName() << std::endl;

    return 0;
    // 作用域结束，entity1, entity2, entity3 的内存被自动回收
}
```

## 2. 在堆上创建对象 (Heap Allocation)

当你需要手动控制对象的生命周期，或者对象太大塞不进栈时，就需要使用堆分配。

- **特点**：使用 `new` 关键字。它不仅在堆上分配内存，还会调用类的构造函数，最终返回一个指向该内存地址的**指针**。
- **缺点**：比栈分配慢。最重要的是，堆内存不受作用域控制，**必须**手动使用 `delete` 关键字来释放内存，否则会导致内存泄漏。

**示例代码：**

```
int main() {
    // 在堆上创建对象，返回指针
    Entity* entity = new Entity("Cherno");

    // 通过指针访问方法，通常使用箭头操作符 (->)
    std::cout << entity->GetName() << std::endl;

    // 必须手动释放内存！
    delete entity;

    return 0;
}
```

## 3. 最佳实践 (Rule of Thumb)

**尽可能在栈上创建对象**。只有当你绝对必须跨作用域使用对象，或者对象实在太大时，才使用堆分配（`new`）。在现代 C++ 中，如果必须使用堆内存，推荐使用智能指针（Smart Pointers）来自动处理 `delete`，从而避免内存泄漏。
