- - # C++ 引用类型

    ### Core Concept (核心概念)

    - **引用是对象的别名**，不是重新创建一个对象。
    - 引用一旦绑定到某个对象，后续通过引用读写，操作的就是**原对象本身**。来源：:contentReference[oaicite:0]{index=0}

    ### Key Points (关键知识点)

    - **类型分类**：
      - **内置类型**：`int`、`char`、`float`、`double`、`bool` 等 C++ 自带基础类型。
      - **复合类型**：由其他类型组合而成，例如数组、结构体、类、指针、引用等。

    - **引用的本质**：
      - 引用是一个已有变量的**别名**。
      - 对引用的操作，等价于对原变量的操作。
      - 引用不产生新的独立对象。

    - **普通赋值与引用绑定的区别**：
      - `int b = a;`：创建新变量 `b`，把 `a` 的值复制过去。
      - `int& b = a;`：`b` 成为 `a` 的别名，二者指向同一个对象。

    - **引用的定义语法**：
      - `int& ref = obj;`
      - `&` 在声明语境中表示**引用类型**，不是取地址运算。

    - **引用必须初始化**：
      - 引用定义时必须绑定到一个已存在的对象。
      - 错误示例：`int& r;`

    - **引用不可重新绑定**：
      - 引用一旦绑定到某个对象，就不能改绑到另一个对象。
      - `r = other;` 的含义是：把 `other` 的值赋给 `r` 所绑定的对象，而不是让 `r` 改绑到 `other`。

    - **没有空引用**：
      - 引用必须绑定到有效对象。
      - 指针可以是 `nullptr`，引用没有对应的“空状态”。

    - **const 引用**：
      - `const int& r = a;`
      - 表示**不能通过引用 r 修改对象**。
      - 但对象本身如果不是 `const`，仍然可以通过其他方式修改。

    - **左值引用**：
      - `T&`
      - 主要用于给已有对象创建别名。
      - 一般只能绑定到左值。

    - **右值引用**：
      - `T&&`
      - C++11 引入，主要服务于**移动语义**和**完美转发**。
      - 它可以绑定到临时对象，但直接写 `int&& r = 10;` 不是它最核心的使用场景。

    - **移动语义**：
      - 右值引用允许在对象即将销毁前“接管”它的资源。
      - 目的：避免不必要的深拷贝，提高大对象、容器、字符串等场景的性能。

    - **完美转发**：
      - 借助模板和 `std::forward`，让函数参数保持原来的值类别继续传递。
      - 核心目标：左值仍按左值传，右值仍按右值传。

    ### Code Snippet (示例代码)

    - 引用的基本行为：

        #include <iostream>

        int main() {
            int a = 100;

        ```cpp
        int& b = a; // b 是 a 的引用，本质是 a 的别名
        
        std::cout << "a = " << a << '\n';
        std::cout << "b = " << b << '\n';
        
        b = 200; // 修改 b，实际修改的是 a
        
        std::cout << "after b = 200\n";
        std::cout << "a = " << a << '\n';
        std::cout << "b = " << b << '\n';
        
        int c = a; // c 是新对象，只是复制了 a 的值
        c = 300;   // 修改 c 不影响 a 和 b
        
        std::cout << "after c = 300\n";
        std::cout << "a = " << a << '\n';
        std::cout << "b = " << b << '\n';
        std::cout << "c = " << c << '\n';
        
        return 0;
        ```
        }

    - const 引用的限制：

        #include <iostream>

        int main() {
            int a = 100;

        ```cpp
        const int& r = a; // 不能通过 r 修改 a
        
        // r = 200; // 错误：r 是 const 引用，禁止通过它修改对象
        
        a = 200; // 正确：a 本身不是 const，可以直接修改
        
        std::cout << "r = " << r << '\n'; // 输出 200
        
        return 0;
        ```
        }

    - 左值引用与右值引用：

        #include <iostream>
        #include <string>

        int main() {
            int a = 10;

        ```cpp
        int& lref = a;     // 左值引用：绑定到已有对象
        int&& rref = 20;   // 右值引用：绑定到临时值
        
        lref = 30; // 修改 lref，实际修改 a
        rref = 40; // rref 本身是一个具名变量，可以被修改
        
        std::cout << "a = " << a << '\n';
        std::cout << "rref = " << rref << '\n';
        
        return 0;
        ```
        }

    ### Common Pitfalls (避坑指南)

    - **误以为引用是新变量**：
      - `int& b = a;` 不会创建一个新的 `int` 对象。
      - `b` 只是 `a` 的另一个名字。

    - **混淆声明中的 `&` 与表达式中的 `&`**：
      - `int& b = a;`：声明引用。
      - `&a`：取变量 `a` 的地址。

    - **误以为引用可以改绑**：
      - `b = c;` 不是让 `b` 引用 `c`。
      - 它只是把 `c` 的值赋给 `b` 当前绑定的对象。

    - **忘记引用必须初始化**：
      - 引用不是指针，不能先声明后绑定。
      - 必须在定义时立即绑定对象。

    - **误解 const 引用**：
      - `const int& r = a;` 只是限制不能通过 `r` 修改。
      - 如果 `a` 本身不是常量，仍然可以直接写 `a = 200;`。

    - **把右值引用当作普通语法糖**：
      - `T&&` 的核心价值不是绑定字面量。
      - 它主要用于移动构造、移动赋值、完美转发等高级场景。

    - **返回局部变量的引用**：
      - 不要返回函数内部局部变量的引用。
      - 局部变量在函数结束后销毁，引用会悬空。
