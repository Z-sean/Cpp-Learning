# C++ 笔记：模板 (Templates)

## 1. 核心概念

模板就像是代码的蓝图，允许编译器根据你提供的规则自动生成代码。使用模板可以避免代码重复（例如为 `int`、`float` 和 `string` 编写相同逻辑的 `Print` 函数）。模板是在编译时被求值的，只有在你实际调用它时，编译器才会为你生成对应的真实代码，否则模板本身并不会作为代码编译。

## 2. 函数模板示例

通过 `template<typename T>` 或 `template<class T>` 可以定义模板。调用时，编译器通常会根据传入的参数自动推导类型 `T`，当然你也可以用尖括号显式指定类型。

```cpp
#include <iostream>
#include <string>

// 定义一个可打印任何类型的函数模板
template<typename T>
void Print(T value) {
    std::cout << value << std::endl;
}

int main() {
    Print(5);                 // 编译器自动推导 T 为 int
    Print<std::string>("Hello"); // 显式指定 T 为 std::string
    Print(5.5f);              // 编译器自动推导 T 为 float
    return 0;
}
```

## 3. 类模板与非类型参数示例

模板不仅限于函数和类型，你也可以为类创建模板，并向其中传递整数等具体的常量值作为模板参数（例如用来在栈上分配固定大小的数组）。

```cpp
#include <iostream>

// 接受数据类型 T 和数组大小 N 的类模板
template<typename T, int N>
class Array {
private:
    T m_Array[N];
public:
    int GetSize() const {
        return N;
    }
};

int main() {
    // 实例化一个包含 5 个 int 的数组类
    Array<int, 5> array;
    std::cout << array.GetSize() << std::endl;
    return 0;
}
```

## 4. 最佳实践

虽然模板非常强大（C++ 标准模板库 STL 就是完全基于模板构建的），但过度使用会导致代码晦涩难懂，并在出错时引发难以排查的编译错误。只有在确实能带来便利的地方（如日志系统、材质系统等需要处理大量未知类型的场景）才应该使用模板，不要滥用它来炫技。
