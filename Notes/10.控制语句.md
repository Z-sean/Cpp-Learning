### C++ 控制流语句核心笔记

- **1. 核心作用**
  - 控制流语句配合循环（如 `for`, `while` 等）使用，用于精确控制程序执行的走向和逻辑。
- **2. `continue` (继续)**
  - 只能在循环内部使用。
  - 它的作用是**跳过当前迭代**的剩余代码，直接强行进入循环的下一次迭代。
- **3. `break` (中断)**
  - 主要用于循环（也可用于 `switch` 语句）。
  - 它的作用是**直接终止（跳出）整个循环**，程序会立刻执行循环体之后的下一行代码。
- **4. `return` (返回)**
  - 可以用在函数中的任何地方，不局限于循环内部。
  - 它的作用是**直接退出当前函数的执行**。如果函数的返回类型不是 `void`，则 `return` 后面必须跟上对应类型的值（如 `return 0;`）。

------

### 示例代码

```
#include <iostream>

int main() {
    // 1. continue 示例
    for (int i = 0; i < 5; i++) {
        if (i % 2 == 0) {
            continue; // 如果是偶数，直接跳过本次迭代，不会执行下面的打印
        }
        std::cout << "Odd number: " << i << std::endl;
    }

    // 2. break 示例
    for (int i = 0; i < 5; i++) {
        if (i == 2) {
            break; // 当 i 等于 2 时，直接跳出整个 for 循环
        }
        std::cout << "Before break: " << i << std::endl;
    }

    // 3. return 示例
    if (true) {
        return 0; // 直接退出 main 函数，整个程序结束
    }

    std::cout << "This will never be printed." << std::endl; // 这里的代码永远不会被执行
}
```
