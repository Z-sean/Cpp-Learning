### C++ 析构函数核心笔记

- **1. 析构函数的本质与作用**
  - 析构函数是与构造函数相对应的特殊方法，**在对象被销毁时自动运行**。
  - 如果说构造函数用于初始化变量和分配内存，那么析构函数的主要作用就是**卸载和清理内存**。这对于防止内存泄漏至关重要，特别是当你在类中使用了手动堆分配（如 `new`）时，必须在析构函数中将其释放（如 `delete`）。
- **2. 基本语法规则**
  - 析构函数的名称必须与类名完全相同，但**前面必须加一个波浪号 (`~`)**。
  - 析构函数没有返回类型，也不能带有任何参数。
- **3. 触发时机 (栈 vs 堆)**
  - **栈分配 (Stack)**：当对象离开其所在的作用域（Scope）时，对象会被自动销毁，析构函数也会随之自动触发。
  - **堆分配 (Heap)**：如果你使用 `new` 关键字在堆上创建了对象，那么只有当你手动调用 `delete` 释放该对象时，析构函数才会被触发。
- **4. 避免手动调用**
  - 虽然在 C++ 中从语法上可以手动调用析构函数（例如写成 `e.~Entity();`），但**极度不推荐**这么做。因为对象最终还是会被系统自动销毁一次，这会导致尝试释放相同的内存两次，从而引发错误或崩溃。

### 示例代码

```
#include <iostream>

class Entity {
public:
    float X, Y;

    // 1. 构造函数：对象创建时立刻调用
    Entity() {
        X = 0.0f;
        Y = 0.0f;
        std::cout << "Created Entity!" << std::endl;
    }

    // 2. 析构函数：前面加波浪号 ~，对象销毁时自动调用
    ~Entity() {
        std::cout << "Destroyed Entity! Memory cleaned up." << std::endl;
    }

    void Print() {
        std::cout << X << ", " << Y << std::endl;
    }
};

void Function() {
    Entity e; // 在栈上创建对象，触发构造函数
    e.Print();
} // 函数作用域结束，对象 e 被销毁，自动触发析构函数

int main() {
    Function();

    // 如果是堆分配，需要手动 delete 才会触发析构函数
    Entity* e2 = new Entity();
    delete e2; // 此时才会打印 "Destroyed Entity!"

    return 0;
}
```
