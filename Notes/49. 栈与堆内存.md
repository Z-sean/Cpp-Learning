# C++ 笔记：栈与堆内存 (Stack vs Heap Memory)

## 1. 核心区别

栈 (Stack) 和堆 (Heap) 都是计算机 RAM 中用于存储程序数据的内存区域。它们的核心区别在于**内存分配的方式**和**对象的生命周期**。

- **栈分配 (Stack Allocation)**：速度极其迅速。在栈上分配内存仅仅是移动栈指针，底层通常只需要一条 CPU 指令。栈变量的数据在内存中紧密相连，并且当作用域结束时，内存会被自动回收（弹出栈），完全免费且安全。
- **堆分配 (Heap Allocation)**：速度较慢且开销更大。使用 `new` 关键字时，系统底层会调用 `malloc`，在**“空闲列表 (free list)”**中搜索足够大的连续内存块，并记录分配信息。此外，堆内存**不受作用域控制**，必须手动调用 `delete` 释放，否则会导致**内存泄漏**。

## 2. 示例代码对比

以下代码展示了如何分别在栈和堆上分配整数、数组以及自定义结构体对象：

```cpp
#include <iostream>

struct Vector3 {
    float x, y, z;
    Vector3() : x(10), y(11), z(12) {}
};

int main() {
    // ==========================================
    // 1. 在栈上分配 (推荐，速度快，自动释放)
    // ==========================================
    int value = 5;  
    int array = {1, 2, 3, 4, 5};
    Vector3 vector;  

    // ==========================================
    // 2. 在堆上分配 (使用 new 关键字，需手动释放)
    // ==========================================
    int* hValue = new int;
    *hValue = 5;

    int* hArray = new int;
    for (int i = 0; i < 5; i++) hArray[i] = i + 1;

    Vector3* hVector = new Vector3();

    // --- 极度重要：清理堆内存 ---
    delete hValue;
    delete[] hArray; // 数组必须使用 delete[]
    delete hVector;

    return 0;
}
```

## 3. 最佳实践 (Best Practices)

**尽可能在栈上分配内存**。只有在以下两种特定情况下才应该考虑使用堆内存：

1. **生命周期需求**：对象的存活时间需要超出创建它的当前作用域（例如你想从函数中返回一个庞大对象的指针）。
2. **数据体积过大**：需要分配的数据量过大（比如几十兆字节的图像纹理），由于栈的容量通常很小（约 2MB），放不下时必须借用堆。
