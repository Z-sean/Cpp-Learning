### C++ 类与结构体中的 Static 核心笔记

- **1. 静态变量 (Static Variables)**
  - 在类或结构体内部将变量标记为 `static` 意味着：**在所有类实例中，该变量只有一个共享实例**。
  - 如果你在一个对象中修改了它，这个改变会反映在所有其他对象中，因为它们指向同一块内存。
  - 由于它们独立于任何具体的对象实例存在，属于整个类，因此必须在类的外部进行**定义**，让链接器能找到它。
- **2. 静态方法 (Static Methods)**
  - 静态方法可以在不创建类实例的情况下直接调用。
  - **关键限制**：静态方法**无法访问**类中的非静态变量。
  - **底层机制**：普通的非静态方法在底层被调用时，编译器会隐式地传入一个指向当前对象实例的参数（即 `this` 指针）。而**静态方法没有这个隐藏的实例引用**，因此它根本不知道应该去访问哪个具体对象的非静态变量。
- **3. 访问建议**
  - 推荐直接通过作用域解析运算符（如 `Entity::x` 或 `Entity::Print()`）来访问静态成员，而不是通过对象实例（如 `e.x`），这样能让代码意图更清晰，表明它们独立于特定对象。

### 示例代码

```
#include <iostream>

struct Entity {
    static int x, y; // 声明静态变量

    static void Print() {
        // 静态方法可以直接访问静态变量
        std::cout << x << ", " << y << std::endl;
        // 注意：如果这里定义了非静态变量，Print 方法是无法访问的
    }
};

// 必须在类外部定义静态变量
int Entity::x;
int Entity::y;

int main() {
    // 推荐的用法：直接通过类名访问静态变量和方法，不需要实例化
    Entity::x = 5;
    Entity::y = 8;
    Entity::Print();

    // 即使实例化了对象，它们也共享同一个 x 和 y
    Entity e1;
    e1.x = 10;
    Entity::Print(); // 此时会打印 10, 8

    return 0;
}
```
