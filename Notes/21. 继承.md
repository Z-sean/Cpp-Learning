### C++ 继承 (Inheritance) 核心笔记

- **1. 继承的本质与核心目标**
  - 继承是面向对象编程 (OOP) 的基础特性之一，它允许我们构建相互关联的类层级结构。
  - 使用继承的最主要原因是为了**避免代码重复 (Code Duplication)**。通过将多个类之间通用的功能和数据提取到一个“基类 (Base Class)”中，我们可以避免多次复制粘贴相同的代码。
- **2. 基类与子类 (Base Class & Subclasses)**
  - **基类 (父类)** 包含共享的通用代码。例如在一个游戏中，所有物体都有位置坐标（`x`, `y`）和移动功能 `Move()`，这就构成了一个通用的 `Entity`（实体）基类。
  - **子类 (派生类)** 从基类分支出来。子类（如 `Player`）不仅会自动拥有基类中的所有属性和方法，还可以添加自己独有的全新数据（如 `Name`）和新功能（如 `PrintName`）。
- **3. 语法与类型特性**
  - 在 C++ 中，通过在类名后加上 `: public BaseClassName` 来实现继承。
  - 一旦继承建立，子类对象将同时具有子类类型和基类类型。例如，`Player` 不仅是 `Player` 类型，它同时也是一种 `Entity`。
  - 同时类的内存大小同时包含继承的内容

### 示例代码

```
#include <iostream>

// 1. 定义基类 Entity，包含所有实体的通用属性和功能
class Entity {
public:
    float X, Y;

    void Move(float xa, float ya) {
        X += xa;
        Y += ya;
    }
};

// 2. 定义子类 Player，使用 : public 继承自 Entity
class Player : public Entity {
public:
    const char* Name; // Player 独有的新属性

    void PrintName() {
        std::cout << Name << std::endl;
    }
};

int main() {
    Player player;

    // Player 自动继承了 Entity 的成员和方法，无需重新编写
    player.X = 0.0f;
    player.Y = 0.0f;
    player.Move(5.0f, 5.0f);

    // 使用 Player 独有的属性和方法
    player.Name = "Cherno";
    player.PrintName();

    return 0;
}
```
