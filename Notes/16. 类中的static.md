### C++ Static 关键字 (类外部) 核心笔记

- **1. Static 的两种作用域**
  - 在 C++ 中，`static` 关键字的含义取决于它是在类/结构体的外部还是内部使用。本节聚焦于在**类外部**的使用。
- **2. 内部链接 (Internal Linkage)**
  - 在类外部将变量或函数标记为 `static` 时，它将具有“内部链接”属性。
  - 这意味着该符号（变量或函数）**仅在当前定义它的翻译单元（即当前的 `.cpp` 文件）内可见**。链接器在寻找符号定义时，不会跨越当前文件去寻找它。
- **3. 防止符号冲突 (Duplicate Symbols)**
  - 如果不使用 `static`，普通的全局变量在链接阶段会对整个项目可见。如果你在两个不同的 `.cpp` 文件中定义了同名的全局变量或函数，链接器会抛出“符号重复定义”的链接错误。
  - 给变量或函数加上 `static`，就相当于把它们变成了该文件的“私有 (private)”成员，这样即使其他文件有同名变量也不会引发冲突。
- **4. 最佳实践**
  - 只要一个变量或函数不需要跨文件被其他 `.cpp` 文件调用，你就应该尽量将其标记为 `static`。这能有效防止全局命名空间污染，避免难以排查的 Bug。

------

### 示例代码

**Static.cpp**

```
// 加上 static，意味着 s_Variable 仅在 Static.cpp 内部可见
static int s_Variable = 5;

// 加上 static，这个函数也仅限当前文件使用
static void Function() {

}
```

**Main.cpp**

```
#include <iostream>

// 如果 Static.cpp 中的变量没有加 static，
// 链接器会因为这里有一个同名的全局变量而报错（重复定义）
int s_Variable = 10;

int main() {
    // 这里打印的是 Main.cpp 中的 s_Variable
    std::cout << s_Variable << std::endl;
    return 0;
}
```
