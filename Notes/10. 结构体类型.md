# 结构体

## 基础使用

- 结构体是一系列相关数据的集合
- 通过函数被传递
- 管理更复杂的数据结构

---

### 结构体定义与成员变量初始化

- 使用`struct`进行结构体定义
- 结构体中的一系列变量称之为成员变量

> {}的代表含义:
>
> 当在函数中，表示开辟一个作用域，其中使用`;`进行分割
>
> 当在`=`右侧时，表示初始化一个列表，使用`,`分割
>
> 当在结构体/类声明后面时，表示成员变量的声明。使用`;`分割

#### 初始化方式一:单独对成员变量初始化

```cpp
struct Point {
    int x;
    int y;
};

// 使用模板
Point p1;       // 第一步：声明变量（此时 x 和 y 可能是随机的垃圾值）
p1.x = 10;      // 第二步：单独赋值
p1.y = 20;
```

#### 初始化方式二:在`{}`中集体初始化

```cpp
struct Student {
    int id;
    double score;
};

// 使用模板
// 方式 A：严格按照结构体内部声明的顺序依次填入
Student s1 = {1, 95.5};

// 方式 B：C++20 标准支持的“指定初始化” (你在之前的 Car 代码里用过！)
Student s2 = {.id = 2, .score = 98.0};
```

#### 初始化方式三:使用构造函数初始化

```cpp
struct Weapon {
    int damage;
    int durability;

    // 构造函数模板（带有冒号初始化列表）
    Weapon(int dmg, int dur) : damage(dmg), durability(dur) {}
};

// 使用模板（就像调用普通函数一样传参）
Weapon sword(50, 100);
```

- 构造函数的模板是:

- ```cpp
  struct 结构体名称 {
      // 1. 成员变量声明
      数据类型 变量1;
      数据类型 变量2;
  
      // 2. 构造函数模板
      结构体名称(数据类型 参数1, 数据类型 参数2) : 变量1(参数1), 变量2(参数2) {
          // 这里可以放一些额外的复杂操作。
          // 如果不需要额外操作，大括号里留空即可！
      }
  };
  ```

  - `: 变量1(参数1), 变量2(参数2)`表示

- 构造函数没有返回值类型

- 构造函数必须与结构体名字一致

- 冒号初始化:通过冒号以后后面的声明，实现在进入 `{}` 之前，把参数值填进成员变量里

### 结构体实现类的输出

- 结构体是自定义的类型，所以无法完整的被输出，但成员变量是具体的类型，可以被输出

- ```cpp
  int main() {
     struct Car {
        std::string brand;
        std::string model;
     };
     Car car = {"bm","x3"};
     std::cout << car.brand << std::endl;//成功输出
  }
  
  ```

- ```cpp
  #include <iostream>
  #include "global.h"
  int main() {
     struct Car {
        std::string brand;
        std::string model;
     };
     Car car = {"bm","x3"};
     std::cout << car << std::endl;//报错:没有匹配std::ostream(即 std::ostream)和Car类型的实参的可行 operator<<。
  }
  
  ```

## 结构体和类

### 差别

- 默认访问控制

  - **结构体（struct）**：默认成员访问权限为 `public`。

  - **类（class）**：默认成员访问权限为 `private`。

- 使用习惯

  - **结构体（struct）**：通常用于纯数据结构，主要存储数据，成员通常是公开的。

  - **类（class）**：用于包含数据和操作数据的函数，支持更加复杂的封装。

### 相似

- 都可以包含**成员变量和成员函数。**

- 都**支持访问控制（public、protected、private）**。

- 都**可以使用继承和多态。**

### 结构体使用

#### 嵌套结构体

- 结构体可以作为成员变量存储在结构体中

#### 结构体数组

- 可以创建一个数组，其中元素是结构体

- ```cpp
  struct Student {
      int id;
      std::string name;
      float grade;
  };
  
  int main() {
      // 创建包含3个学生信息的数组
      Student students[3] = {
          {1001, "Alice", 89.5f},
          {1002, "Bob", 92.0f},
          {1003, "Charlie", 85.0f}
      };
  
      for (int i = 0; i < 3; ++i) {
          std::cout << "学生ID: " << students[i].id 
                    << ", 姓名: " << students[i].name 
                    << ", 成绩: " << students[i].grade << std::endl;
      }
  
      return 0;
  }
  ```

#### 结构体指针

- 可以创建指针变量指向结构体，但使用指针访问结构体本身时，使用`->`而不是`.`

- ```cpp
  struct Car {
      std::string brand;
      std::string model;
      int year;
  };
  
  int main() {
      Car car = {"Toyota", "Camry", 2020};
      Car* carPtr = &car;
  
      std::cout << "品牌: " << carPtr->brand << std::endl;
      std::cout << "型号: " << carPtr->model << std::endl;
      std::cout << "年份: " << carPtr->year << std::endl;
  
      return 0;
  }
  ```

#### 结构体别名

- 结构体一般用作公共数据的存储容器，可能会遇到复杂命名，可以通过`typedef`进行符合自身要求的命名,或者使用`using`也可以

- ```cpp
  typedef struct {
      int id;
      std::string name;
      float grade;
  } Student;
  
  // 或者使用 `using`（C++11 及以上）
  using Student = struct {
      int id;
      std::string name;
      float grade;
  };
  ```

#### 结构体函数

- 结构体虽然多用于存储数据，但也被允许也有函数成员变量

```cpp
struct Book {
    std::string title;
    std::string author;
    int pages;

    // 成员函数
    void printInfo() const {
        std::cout << "书名: " << title 
                  << ", 作者: " << author 
                  << ", 页数: " << pages << std::endl;
    }
};
```

### 结构体可以作为参数类型或函数返回值使用

```cpp
struct Point {
    int x;
    int y;
};

// 通过值传递
void printPoint(Point p) {
    std::cout << "Point(" << p.x << ", " << p.y << ")" << std::endl;
}

// 通过引用传递
void movePoint(Point& p, int dx, int dy) {
    p.x += dx;
    p.y += dy;
}
//通过指针传递
void movePoint(Point* p,int dx, int dy){
    p->x += dx;
    p->y += dy;
}
```

```cpp
struct Rectangle {
    int width;
    int height;
};

// 计算面积的结构体
struct Area {
    int value;
};

// 函数返回结构体
Area calculateArea(Rectangle rect) {
    Area area;
    area.value = rect.width * rect.height;
    return area;
}

int main() {
    Rectangle rect = {5, 10};
    Area rectArea = calculateArea(rect);
    std::cout << "矩形面积: " << rectArea.value << std::endl;
    return 0;
}
```
