### C++ 可见性 (Visibility) 核心笔记

- **1. 可见性的本质与影响**
  - 可见性是面向对象编程中的概念，用于精确控制类的成员变量和方法能被谁访问和调用。
  - **零性能影响**：可见性对程序的实际运行、底层机器码执行或性能表现没有任何影响。它纯粹是为了帮助开发者更好地组织和维护代码。
- **2. 默认可见性**
  - 在 C++ 中，`class`（类）内部成员的默认可见性是 `private`（私有）。
  - `struct`（结构体）内部成员的默认可见性是 `public`（公有）。
- **3. 三种可见性修饰符**
  - **`private` (私有)**：只有该类内部的代码以及其 `friend`（友元）可以访问。子类或类外部的代码（如 `main` 函数）均无法访问。
  - **`protected` (受保护)**：该类自身以及继承体系中的所有子类可以访问，但类外部的代码无法访问。
  - **`public` (公有)**：任何人（任何作用域）都可以直接访问，包括类内部、子类以及类外部的代码。
- **4. 为什么不把所有成员都设为 `public`？**
  - 良好的可见性设置可以向其他开发者（以及未来的自己）清晰地传达类的正确 API 使用方式。
  - **举个例子**：在设计 UI 按钮时，如果坐标变量是 `public`，外部直接修改坐标并不会触发屏幕刷新。通过将坐标变量设为 `private`，并提供一个公有的 `SetPosition()` 方法，你就可以确保在修改坐标的同时调用底层刷新显示的代码，防止因误操作产生 Bug。

### 相关示例代码

```
#include <iostream>

class Entity {
private:
    int X, Y; // 仅 Entity 内部及其友元可访问

protected:
    int speed; // Entity 及其子类（如 Player）可访问

public:
    // 任何地方都可以访问
    Entity() {
        X = 0;
        Y = 0;
        speed = 2;
    }

    void Print() {
        std::cout << "Entity Printed." << std::endl;
    }
};

class Player : public Entity {
public:
    void Move() {
        // X = 5; // 错误！X 是 private，子类无法访问
        speed = 5; // 正确！speed 是 protected，子类可以访问
    }
};

int main() {
    Entity e;
    Player p;

    // e.X = 10;     // 错误！X 是 private，外部无法访问
    // e.speed = 10; // 错误！speed 是 protected，外部无法访问

    e.Print(); // 正确！Print() 是 public 的
    p.Move();  // 正确！Move() 是 public 的

    return 0;
}
```
