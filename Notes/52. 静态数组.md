# C++ 笔记：静态数组 (std::array)

在 C++11 中，标准库引入了 `std::array`，这是一种内置的、分配在栈上的固定大小数组数据结构。

## 1. 核心优势

- **大小追踪**：`std::array` 在内部维护了数组的长度，你可以直接调用 `.size()` 获取大小，无需像 C 语言风格的原始数组那样手动维护大小变量。
- **安全性**：它提供了可选的边界检查机制，使用起来比原始数组更安全，且不会带来不必要的性能损耗。
- **迭代器支持**：你可以轻松获取该数组的迭代器，这使得它能完美配合基于范围的 for 循环 (range-based for loop) 以及各种标准库算法。

## 2. 语法与使用

使用时必须包含 `<array>` 头文件。由于它是**基于模板实现**的，因此在声明时需要同时指定**数据类型**和**数组大小**，且大小必须是在编译时已知的常量表达式。

## 3. 示例代码

```cpp
#include <iostream>
#include <array> // 引入 array 头文件

int main() {
    // 创建一个包含 5 个整数的静态数组
    std::array<int, 5> collection = {1, 2, 3, 4, 5};

    // 直接获取并打印数组大小
    std::cout << "Array size: " << collection.size() << std::endl;

    // 利用迭代器特性使用范围 for 循环进行遍历
    for (int value : collection) {
        std::cout << value << std::endl;
    }

    return 0;
}
```
