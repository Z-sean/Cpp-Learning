### C++ Const 关键字核心笔记

- **1. Const 的本质**
  - `const` 并不是一个会改变底层机器码执行方式的“魔法”，它更多的是开发者向编译器和其他程序员做出的**承诺 (Promise)**，承诺某个变量或状态不会被修改。
  - 使用 `const` 可以让代码逻辑更清晰，并通过编译器在编译期帮你找出试图打破这些承诺的错误。
- **2. 基础常量**
  - 最简单的用法是定义不能改变的变量，比如 `const int MAX_AGE = 90;`，防止后续代码意外修改该值。
- **3. Const 与指针的结合**
  - **不能修改数据**：`const int* a`（或 `int const* a`），你不能通过解引用来修改该地址里的数据，但你可以让指针 `a` 重新指向另一个变量的地址。
  - **不能改变指向**：`int* const a`，你可以修改指针指向的内存数据，但指针 `a` 永远只能指向初始化时绑定的那个地址。
  - **两者皆不可**：`const int* const a`，数据和指针的指向都处于锁定状态，无法修改。
- **4. 类方法 (Methods) 中的 Const**
  - 在类方法声明的末尾加上 `const`（例如 `int GetX() const`），表示这个方法是一个**只读方法**，它承诺不会修改该类内部的任何成员变量。
  - **关键约束**：如果你将对象以常量引用（`const Entity&`）的方式传递给某个函数，那么在该函数内部，你**只能**调用这个对象里被标记为 `const` 的方法。
- **5. `mutable` (可变) 关键字**
  - `mutable` 允许绕过 `const` 方法的限制。
  - 如果一个类成员变量被标记为 `mutable`，那么即使是在被标记为 `const` 的只读方法中，该变量依然可以被修改（常用于修改不影响类核心状态的调试计数器等）。

### 示例代码

```
#include <iostream>

class Entity {
private:
    int m_X, m_Y;
    // 使用 mutable 标记，允许它在 const 方法中被修改
    mutable int m_DebugCount = 0;

public:
    Entity() { m_X = 0; m_Y = 0; }

    // 1. Const 方法：承诺不修改类的核心成员变量
    int GetX() const {
        m_DebugCount++; // 这是合法的，因为 m_DebugCount 是 mutable
        return m_X;
    }

    // 非 Const 方法：可以自由修改成员变量
    void SetX(int x) {
        m_X = x;
    }
};

// 2. 按常量引用传参 (避免拷贝对象)
void PrintEntityX(const Entity& e) {
    // 只能调用 e 内部被标记为 const 的方法
    std::cout << e.GetX() << std::endl;

    // e.SetX(5); // 错误！SetX 不是 const 方法，无法在 const 引用上调用
}

int main() {
    int a = 5;
    int b = 10;

    // 3. 指针与 Const 的三种组合

    // 指向常量数据的指针 (不能修改数据，可以改变指向)
    const int* ptr1 = &a;
    // *ptr1 = 2; // 错误
    ptr1 = &b;    // 正确

    // 常量指针 (可以修改数据，不能改变指向)
    int* const ptr2 = &a;
    *ptr2 = 2;    // 正确
    // ptr2 = &b; // 错误

    // 指向常量数据的常量指针 (数据和指向都不可修改)
    const int* const ptr3 = &a;

    return 0;
}
```
