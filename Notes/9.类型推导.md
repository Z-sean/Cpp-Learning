# 类型推导

## 类型别名

- 使用类型别名让复杂的类型名字变得简单明了、易于理解和使用，还有助于清楚地知道使用该类型的真实目的。

- 有以下两种定义方式：

  - ```cpp
    //wages 是double的同义词
    typedef double wages;
    //base是double的同义词,p是double*的同义词
    typedef wages base, *p;
    ```

    使用`typedef` 关键字

  - ```cpp
    //64位整型
    using int64_t = long long;
    ```

    使用`using`关键字

## 指针&常量&类型别名

```cpp
typedef char * pstring;
const pstring cstr = 0;
const pstring *ps;
```

- `const`是对给定类型的变量修饰，这里`pstring`是一个指向`char`的指针，所以`const pstring`就是一个常量指针，而不是指向常量的指针

### auto类型推导

- `cpp`要求变量声明时类型匹配，我们经常把表达式的值赋给变量，这要求我们知道表达式的值的类型

- C++11引入了`auto类型说明符`，编译器处理时会自动分析表达式所属的类型

  - `auto`让编译器**通过初始值来判断变量类型，所以`auto`定义的变量必须有初始值**

  - ```cpp
    //计算求和
    int age1 = 20;
    int age2 = 35;
    auto age_add = age1+age2;
    ```

- 使用`auto`**可以声明多个变量，但一条声明语句只能有一个基本类型，所以`auto`声明变量的语句中必须统一基本类型**

- ```cpp
  //正确, i是整数，p是整型指针
  auto i= 0, * p= &i;
  //错误, sz是整型，pi是double
  //auto sz = 0, pi = 3.14;
  ```

---

### 复合类型与auto

- `auto x = expr`【简单传值】：创建一个复印件，无关初始值，**忽略顶层`const`忽略引用**
- `auto& x = expr;` 或 `const auto& x = expr;` 或 `auto* x = expr;`【借用】：告知编译器本身是一个指针/引用，同时保留初始值的`const`，不过不保留引用类型
  - 普通的`auto&`不能绑定一个右值，因为右值是一个临时值，无法被引用。
- `auto&& x = expr;`，【万能引用】：根据等号右侧进行推测，若为左值，就是一个左值引用，若是一个右值，就是一个右值引用。

## decltype

- 型说明符`decltype`，它的作用是**选择并返回操作数的数据类型**。在此过程中，编译器分析表达式并得到它的类型，却不实际计算表达式的值

- 一般情况下`decltype`是所见即所得，但也有特殊情况

  - ```cpp
    {
        //decltype的结果可以是引用各类型
        int i = 42, *p = &i, &r = i;
        //正确，假发的结果是int，因此b是一个未初始化的int
        decltype(r + 0) b;
        //错误，c是int&，必须初始化
        //decltype(*p) c;
    }
    ```

  - 这里引用类型和int类型进行运算，结果是一个int类型

  - 若表达式表达的是解引用操作，那么其类型就是一个引用类型

  - 若表达式外包裹一层括号，那么会被当作一个表达式，变量是一种可以作为赋值语句**左值**的特殊表达式，所以最后的结果是一个引用类型
    ```cpp
    //decltype的表达式如果加上了括号的变量，结果就是引用
    //错误，d是int&，必须初始化
    //decltype((i)) d;
    //正确,e是一个未被初始化的int类型值
    decltype(r) e = i;
    ```
