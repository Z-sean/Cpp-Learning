# 指针

## 什么是指针

- 指针**存放的是数据的地址**，而不是数据本身，通过指针，我们可以直接操作数据==> 指针 == 地址
- 指针**本身是一个对象**，允许对指针进行赋值与拷贝，在指针的生命周期内，可以指向不同的对象
- 指针**不需要在定义时赋值**，在作用域内，若指针没有被初始化，那会会拥有一个不确定的值

## 指针的赋值方式

- 指针有两种赋值方式

  - 直接赋值内存地址
  - 通过地址运算符赋值【**变量地址 = &变量名**】

- ```cpp
  //定义ptr2并且赋值，指向var地址
  int var = 10;
  int *ptr2 = &var;
  ```

  - `ptr2`是存放var的地址，`*`表示其是一个指针变量，`int`t表示该指针指向一个int类型

- 指针本身也是一个对象，所以指针地址也可以被另一个指针存储

  - ```cpp
    //定义ptr2并且赋值，指向var地址
    int var = 10;
    int *ptr2 = &var;
    //ptr_address 存储ptr2的地址
    int** ptr_address = &ptr2;
    std::cout << "var 的地址为: " << &var << std::endl;
    std::cout << "ptr2 存储的值为: " << ptr2 << std::endl;
    std::cout << "ptr2 地址为: " << &ptr2 << std::endl;
    std::cout << "ptr_address 的值为: " << ptr_address << std::endl;
    ```

  - `int** ptr_address = &ptr2;`这里"ptr_address"存放的是地址，`*`表示这是一个指针变量，`int*`表示该指针指向的是一个指针变量。

### 类型匹配

- 指针在声明时，必须指定类型，所以在赋值时，必须类型匹配

- 若指针指向一个与其指针类型不匹配的变量，会**产生错误**

  - ```cpp
    double dval = 3.14;
    //正确，初始值是double类型的对象的地址
    double *pd = &dval;
    //正确，初始值是指向double对象的指针
    double *pd2 = pd;
    //错误,pi的类型和pd类型不匹配
    //int * pi = pd;
    //错误，视图把double型对象的地址赋值给int型指针
    //int * pi = &dval;
    ```

## 指针值

1. 指向一个对象
2. 指向一个对象紧邻的空间
3. 空指针，即指针没有任何对象指向
4. 无效指针，上述情况之外所有值

对**无效指针的访问或拷贝操作都会引发错误**，编译器不会检查此类错误，访问无效指针的后果无法预估，因此需要特别注意。

虽然第二类第三类是有效指针，但这些指针没有指向任何指，所以试图访问该类指针的行为也是不允许的，其后果是无法预测的

## 利用指针访问对象

- 同样的，可以使用`*`(解引用)方式来访问指针所指向的值

- ```cpp
  //访问对象
  int ival = 42;
  //p_int存放着ival的地址，或者说p_int是指向变量ival的指针
  int * p_int = &ival;
  //由符号*得到指针p所指向的对象，输出42
  std::cout << *p_int ;
  ```

## 利用指针修改对象

- 我们可以通过解引用修改指向的对象数据

```cpp
//访问对象
int ival = 42;
//p_int存放着ival的地址，或者说p_int是指向变量ival的指针
int * p_int = &ival;
//由符号*得到指针p所指向的对象，输出42
std::cout << *p_int << std::endl;
//由符号*得到指针p所指向的对象，即可经由p_int为变量ival赋值
*p_int = 0;
std::cout << * p_int << std::endl;
//打印ival的值
std::cout << "ival 的值为" << ival << std::endl;
```

- **解引用只适用于有明确指向的有效指针**

## 符号的多重含义

- `&`和`*`在声明与表达式中可以起到不同作用
- 在表达式中:
  - `&`：取地址符
  - `*`：解引用
- 在声明中:
  - `&`：引用
  - `*`：指针

## 空指针

- ```cpp
  //空指针定义方式
  //C++11 最推荐方式
  int *p1 = nullptr;
  //直接将p2初始化为字面量0
  int *p2 = 0;
  //需要使用#include<cstdlib>
  //等价于int * p3 = 0;
  int *p3 = NULL;
  std::cout << "p1: " << p1 << std::endl;
  std::cout << "p2: " << p2 << std::endl;
  std::cout << "p3: " << p3 << std::endl;
  ```

- `nullptr`是现代推荐的方式，是一个特殊类型的字面值

- 通过将指针初始化为字面值0来生成空指针

- 再过去还有使用NULL来初始化空指针，这个变量在头文件`cstdlib`中定义，它的值就是0。

- 注意事项⚠️:
  - 把int变量赋值给指针变量是错误操作，即使该值为0也不行

## 地址变化

- 我们可以通过修改指针指向的地址来获取不同变量
- 指针和引用都是对其他对象的间接访问，但不同的是**引用本身并不是一个对象**
  - 引用一旦被定义就无法换绑
  - 指针没有这种限制

## 指针判空

- 通过`if`进行判断
- 在Cpp中，0为false，除此之外为true

```cpp
//空指针判断
int * empty_pointer2 = nullptr;
if(!empty_pointer){
    std::cout << "empty_pointer is empty" << std::endl;
}

int test = 100;
int * normal_pointer2 = &test;
if(normal_pointer2){
    std::cout << "normal pointer is not empty" << std::endl;
}
```

- 指针同样可以支持比较运算,判断相等（==），判断不等(!=)

```cpp
//判断指针是否相等
if(normal_pointer2 != empty_pointer){
    std::cout << "normal_pointer 和 empty_pointer 不相等"<< std::endl;
}
```

## 万能指针

- void＊是一种特殊的指针类型，可用于存放任意对象的地址。一个void＊指针存放着一个地址

```cpp
//万能指针
double obj = 3.14, *obj_pd = &obj;
//void 可以存放任何类型的对象的地址
void * pv = &obj;
//pv 可以存储任意类型的地址
pv = obj_pd;
```

- **不能直接操作void＊指针所指的对象，因为我们并不知道这个对象到底是什么类型，也就无法确定能在这个对象上做哪些操作。**

- 一般可以用作:
  - 与别的指针比较
  - 作为函数的输入&输出
  - 赋值另一个`void*`

## 二级指针&多级指针

```cpp
//以指针为例，指针是内存中的对象，像其他对象一样也有自己的地址，
// 因此允许把指针的地址再存放到另一个指针当中。通过＊的个数可以区分指针的级别。
// 也就是说，＊＊表示指向指针的指针，＊＊＊表示指向指针的指针的指针，以此类推：
int ival4= 1024;
// pival4指向了int型的数
int *pival4 = &ival4;
//ppi指向了一个int型的指针
int ** ppi = &pival4;

std::cout << "The value of ival\n"
    << "direct value: " << ival4 << "\n"
    << "indirect value: " << *pival4 << "\n"
    << "doubly indirect value : " << **ppi
    << std::endl;
```

## 指针的引用

- 引用本身不是一个对象，所以引用不存在指针，相反，指针是一个对象，所以指针有引用

- ```cpp
  //引用本身不是一个对象，因此不能定义指向引用的指针。
  // 但指针是对象，所以存在对指针的引用
  int init = 42;
  // pinit是一个int型的指针
  int *pinit;
  // rpinit是一个对指针pinit的引用
  int *& rpinit = pinit;
  // rpinit引用了一个指针，因此给rpinit赋值&init就是令pinit指向init
  rpinit = &init;
  //解引用rpinit得到i,也就是p指向的对象，将init改为0
  *rpinit = 0;
  ```

## 指针运算

- 指针支持算数运算，包括递增（++）和递减（--），对指针的运算操作会修改指针指向的地址。**这种操作只限于指向数组元素的指针**
  - 指针指向的是**数组的第一个元素**，根据不同类型的内存大小，系统可以获取全部变量内容
  - **数组名在大多数表达式里会自动转换成“指向首元素的指针”**，所以通常不需要写 `&`
