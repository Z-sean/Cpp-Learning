### C++ 构造函数 (Constructors) 核心笔记

- **1. 构造函数的本质与作用**
  - 构造函数是一种特殊的方法，**在每次实例化（创建）对象时自动运行**。
  - 它的首要作用是**初始化内存**。在 C++ 中，如果你不手动初始化基本数据类型（如 `int`、`float`），它们将保留内存中残留的随机垃圾值，甚至导致编译错误。
- **2. 基本语法规则**
  - 构造函数的名称**必须与类名完全相同**。
  - 构造函数**没有返回类型**（连 `void` 都不写）。
- **3. 默认构造函数 (Default Constructor)**
  - 如果你不编写任何构造函数，C++ 编译器会自动为你提供一个默认构造函数，但**它什么都不会做**（不会像 Java 那样帮你把数字初始化为 0）。
- **4. 构造函数重载与参数**
  - 你可以像普通函数一样重载构造函数，为它们提供不同的参数，以便在创建对象时直接传入初始值。
- **5. 禁用实例化**
  - 如果你的类只包含静态方法（例如一个只提供工具函数的 `Log` 类），你不希望任何人实例化它。
  - 你可以将构造函数标记为 `private`，或者在现代 C++ 中直接写 `Log() = delete;` 来彻底删除默认构造函数。

------

### 示例代码

```
#include <iostream>

class Entity {
public:
    float X, Y;

    // 1. 默认构造函数：手动将成员初始化为 0
    Entity() {
        X = 0.0f;
        Y = 0.0f;
    }

    // 2. 带参数的构造函数（函数重载）
    Entity(float x, float y) {
        X = x;
        Y = y;
    }

    void Print() {
        std::cout << X << ", " << Y << std::endl;
    }
};

class Log {
public:
    // 3. 删除默认构造函数，防止类被实例化
    Log() = delete;

    static void Write(const char* message) {
        std::cout << message << std::endl;
    }
};

int main() {
    // 调用默认构造函数，X和Y被初始化为0
    Entity e1;
    e1.Print(); // 输出: 0, 0

    // 调用带参数的构造函数
    Entity e2(10.0f, 5.0f);
    e2.Print(); // 输出: 10, 5

    // Log log; // 错误！默认构造函数已被删除
    Log::Write("Hello!");

    return 0;
}
```
