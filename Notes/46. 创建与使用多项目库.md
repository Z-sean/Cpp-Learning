# C++ 笔记：在 Visual Studio 中创建与使用多项目库 (Multiple Projects)

## 1. 核心概念

在较大型的 C++ 项目中，将核心代码提取为独立的库 (Library)，并由可执行程序 (Executable) 来引用是非常常见的做法。在 Visual Studio 中，你可以通过在一个解决方案 (Solution) 内创建多个项目 (Projects) 来完美管理这种架构。

## 2. 关键配置步骤

- **设置静态库**：在你的库项目（例如名为 `engine`）的属性中，将“配置类型 (Configuration Type)”修改为**静态库 (Static library)**。
- **配置包含目录 (Include Directories)**：在可执行项目（例如名为 `game`）中，为了避免使用脆弱的相对路径（如 `../../engine/source`），应在项目属性的 C/C++ 附加包含目录中，使用 Visual Studio 的宏来设置绝对路径。例如使用 `$(SolutionDir)engine\source`。
- **添加项目引用 (References)**：无需手动去配置链接器的 `.lib` 输入，只需右键点击可执行项目 -> 添加 (Add) -> 引用 (Reference)，然后勾选你的库项目。这不仅会自动链接库，还会建立项目间的构建依赖关系（确保每次编译可执行程序前，都会优先编译最新的库代码）。

## 3. 示例代码

**库项目 (engine)** `engine.h`

```cpp
namespace engine {
    void PrintMessage();
}
engine.cpp
#include "engine.h"
#include <iostream>

namespace engine {
    void PrintMessage() {
        std::cout << "Hello World!" << std::endl;
    }
}
```

**可执行项目 (game)** `application.cpp`

```cpp
#include "engine.h" // 只要配置了附加包含目录，就可以这样直接引用
#include <iostream>

int main() {
    engine::PrintMessage();

    std::cin.get();
    return 0;
}
```

通过这种方式静态链接后，生成的可执行文件（`.exe`）将独立包含所有的库代码，不需要额外携带任何外部 DLL 文件即可运行。
